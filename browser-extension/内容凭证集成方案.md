# 内容凭证集成方案

## 一、内容凭证（Content Credentials）概述

### 1.1 什么是内容凭证？

**内容凭证** 是由Adobe、Twitter、Microsoft等公司联合推出的内容溯源标准，基于C2PA（Coalition for Content Provenance and Authenticity）技术规范。

**核心目标**：
- 记录内容的来源
- 追踪内容的修改历史
- 验证内容的真实性
- 防止内容篡改

---

### 1.2 内容凭证的4个核心特性

| 特性 | 说明 | 一鉴到底对应 |
|------|------|-------------|
| **1. 将来源信息与内容关联** | 记录内容的创建者、工具、时间等信息 | ✅ 创作平台识别 + 时间戳 |
| **2. 每次更新都添加签名** | 编辑、修改等操作都生成数字签名 | ✅ 指纹证据链（SHA-256） |
| **3. 查看显示内容来源的日志** | 提供完整的内容历史记录 | ✅ 创作时间线报告 |
| **4. 核对真伪** | 任何人都可以验证内容的真实性 | ✅ 指纹链验证 |

---

## 二、内容凭证 vs 一鉴到底

### 2.1 技术架构对比

| 对比项 | 内容凭证（CAI） | 一鉴到底 |
|--------|----------------|-----------|
| **标准** | C2PA国际标准 | 自研证据链标准 |
| **签名算法** | JWS（JSON Web Signature） | SHA-256哈希 |
| **元数据格式** | JSON-LD + XMP | JSON |
| **存储方式** | 嵌入内容文件 | 本地存储+报告导出 |
| **验证方式** | CAI验证器 | 指纹链验证 |
| **兼容性** | 跨平台标准 | 浏览器插件专有 |

---

### 2.2 功能对比

| 功能 | 内容凭证 | 一鉴到底 | 集成方案 |
|------|---------|---------|---------|
| **创作者信息** | ✅ 支持 | ✅ 支持 | 兼容CAI格式 |
| **创作工具** | ✅ 记录 | ✅ 记录平台 | 映射到CAI工具字段 |
| **创作时间** | ✅ 时间戳 | ✅ NTP时间戳 | 兼容CAI时间格式 |
| **修改历史** | ✅ 完整记录 | ✅ 操作时间线 | 转换为CAI动作 |
| **数字签名** | ✅ JWS签名 | ✅ SHA-256指纹 | 升级为JWS |
| **验证机制** | ✅ CAI验证器 | ✅ 指纹验证 | 兼容CAI验证 |

## 三、集成方案设计

### 3.1 C2PA标准集成

#### 方案1：元数据嵌入（推荐）

**实现方式**：
```javascript
// 导出报告时嵌入C2PA元数据
function generateReportWithC2PA(session) {
  // 1. 生成标准证据链报告
  const report = generateEvidenceReport(session);

  // 2. 创建C2PA元数据
  const c2paMetadata = {
    "@context": "https://c2pa.org/schema",
    "claim_generator": "一鉴到底 v1.1.0",
    "created_at": session.startTime,
    "actions": session.operations.map(op => ({
      "action": op.type,
      "when": op.timestamp,
      "software_agent": session.platform.name
    })),
    "assertions": [
      {
        "label": "c2pa.created_by",
        "data": {
          "name": session.user,
          "identifier": session.userId
        }
      },
      {
        "label": "c2pa.source",
        "data": {
          "name": session.platform.name,
          "url": session.platform.url
        }
      }
    ],
    "hash_proofs": session.fingerprints.map(fp => ({
      "algorithm": "SHA-256",
      "value": fp.hash,
      "created_at": fp.timestamp
    }))
  };

  // 3. 嵌入到报告HTML中
  const reportWithC2PA = `
    <!-- C2PA Metadata (JSON-LD) -->
    <script type="application/ld+json">
    ${JSON.stringify(c2paMetadata, null, 2)}
    </script>

    ${report}
  `;

  return reportWithC2PA;
}
```

#### 方案2：独立C2PA清单文件

**实现方式**：
```javascript
// 生成独立的C2PA清单文件
function generateC2PAManifest(session) {
  return {
    "@context": "https://c2pa.org/manifest-schema",
    "claim_generator": "一鉴到底 v1.1.0",
    "claim_generator_info": {
      "name": "一鉴到底",
      "version": "1.1.0",
      "icon": "https://yijiandaodi.com/icon.png"
    },
    "created_at": session.startTime,
    "meta_data": {
      "platform": session.platform.name,
      "platform_type": session.platform.type,
      "operation_count": session.operations.length,
      "session_id": session.sessionId
    },
    "actions": session.operations.map((op, index) => ({
      "action": mapToC2PAAction(op.type),
      "when": op.timestamp,
      "software_agent": {
        "name": session.platform.name,
        "version": "latest"
      },
      "changes": op.data?.preview || ""
    })),
    "assertions": [
      {
        "label": "stdc.created_by",
        "data": {
          "name": session.user || "匿名用户",
          "identifier": session.userId || generateUUID()
        }
      },
      {
        "label": "stdc.source",
        "data": {
          "name": session.platform.name,
          "url": session.platform.url,
          "type": session.platform.type
        }
      },
      {
        "label": "yijiandaodi.fingerprint_chain",
        "data": {
          "algorithm": "SHA-256",
          "hashes": session.fingerprints.map(fp => fp.hash),
          "chain_integrity": true
        }
      }
    ],
    "signature": {
      "algorithm": "SHA-256",
      "value": generateSessionHash(session),
      "certificate": null // 可选：CA证书
    }
  };
}

// 操作类型映射到C2PA动作
function mapToC2PAAction(operationType) {
  const mapping = {
    'text_input': 'c2pa.edited',
    'ai_prompt': 'c2pa.created',
    'ai_response': 'c2pa.created',
    'image_generate': 'c2pa.created',
    'copy': 'c2pa.copied',
    'paste': 'c2pa.pasted',
    'save': 'c2pa.saved',
    'export': 'c2pa.exported'
  };

  return mapping[operationType] || 'c2pa.unknown';
}
```

### 3.2 验证机制集成

#### 方案1：指纹链验证（现有）

```javascript
// 一鉴到底指纹链验证
function verifyFingerprintChain(fingerprints) {
  for (let i = 1; i < fingerprints.length; i++) {
    const current = fingerprints[i];
    const previous = fingerprints[i - 1];

    // 验证链式关系
    const expectedHash = generateHash({
      operation: current.operationId,
      prevHash: previous.hash,
      timestamp: current.timestamp
    });

    if (current.prevHash !== previous.hash) {
      return {
        valid: false,
        error: `指纹链断裂：第${i}个指纹的前序哈希不匹配`
      };
    }

    if (current.hash !== expectedHash) {
      return {
        valid: false,
        error: `指纹验证失败：第${i}个指纹哈希不匹配`
      };
    }
  }

  return {
    valid: true,
    message: '指纹链完整，验证通过'
  };
}
```

```javascript
async function verifyC2PASignature(manifest) {

      return {
        valid: false,
        error: '不支持的签名算法'
      };
    }

    if (!manifest.claim_generator.includes('一鉴到底')) {
      return {
        valid: false,
        error: '声明生成器不匹配'
      };
    }

    // 3. 验证哈希

      // ...
    }

    return {
      valid: true,
      message: 'C2PA签名验证通过',

```

```
3. 点击"验证"按钮
4. 查看验证结果
```

**验证流程**：
```javascript
// 在报告中提供验证功能
function verifyReport(reportData) {
  const results = [];

  // 1. 验证指纹链
  if (reportData.fingerprints) {
    const fingerprintResult = verifyFingerprintChain(reportData.fingerprints);
    results.push({
      type: '指纹链验证',
      ...fingerprintResult
    });
  }

  // 2. 验证C2PA签名
  if (reportData.manifest) {
    const c2paResult = verifyC2PASignature(reportData.manifest);
    results.push({
      type: 'C2PA签名验证',
      ...c2paResult
    });
  }

  // 3. 验证时间戳
  if (reportData.startTime) {
    const timestampValid = new Date(reportData.startTime) instanceof Date;
    results.push({
      type: '时间戳验证',
      valid: timestampValid,
      message: timestampValid ? '时间戳格式正确' : '时间戳格式错误'
    });
  }

  return results;
}
```
