# Creative Commons（CC）许可证快速指南

## 一、CC许可证概述

**Creative Commons（知识共享）** 是一套标准化的开源授权协议，帮助创作者明确作品的使用权限。

**核心价值**：
- 保护创作者权益
- 明确使用范围
- 促进素材流通
- 避免版权纠纷

## 三、许可证详细说明

### 1. CC BY（署名）
**最宽松的许可证**

✅ **允许**：
- 商业使用
- 任意改编、混音、扩展
- 任何媒介或格式分发

⚠️ **唯一要求**：
- 必须注明原作者

💡 **适用场景**：
- 开源素材库（Unsplash/Pexels等）
- 想让作品最大传播
- 不介意商业使用

**示例标注**：
```
图片来源：张三 CC BY 4.0
本作品基于原作者作品进行改编
```

---

### 2. CC BY-SA（署名-相同方式共享）
**Wikipedia使用的许可证**

✅ **允许**：
- 商业使用
- 改编、混音、扩展

⚠️ **特殊要求**：
- 必须注明原作者
- **改编作品必须用相同许可证**

💡 **适用场景**：
- 维基百科式协作创作
- 想保持作品开放性
- 防止改编作品被封闭

**示例标注**：
```
本作品基于张三作品改编
原作品采用CC BY-SA 4.0协议
本作品同样采用CC BY-SA 4.0协议
```

---

### 3. CC BY-ND（署名-禁止演绎）
**保持作品原样**

✅ **允许**：
- 商业使用
- 复制和分发

❌ **禁止**：
- 任何形式的改编、修改
- 混音、扩展

💡 **适用场景**：
- 官方文档、声明
- 不希望被修改的作品
- 保持完整性的内容

**示例标注**：
```
本作品采用CC BY-ND 4.0协议
禁止改编、修改或演绎
仅允许原样复制和分发
```

---

### 4. CC BY-NC（署名-非商业使用）
**禁止商业用途**

✅ **允许**：
- 非商业使用
- 改编、混音、扩展

❌ **禁止**：
- 任何商业用途
- 商业目的的分发

💡 **适用场景**：
- 教育素材
- 个人创作分享
- 不想被商用赚钱

**非商业定义**：
- 主要目的不是为了商业利益
- 或金钱补偿的使用

**示例标注**：
```
本作品采用CC BY-NC 4.0协议
仅允许非商业用途使用
商业使用请联系原作者
```

---

### 5. CC BY-NC-SA（署名-非商业-相同方式共享）
**学术风格许可证**

✅ **允许**：
- 非商业使用
- 改编、混音、扩展

⚠️ **特殊要求**：
- 必须注明原作者
- 改编作品必须用相同许可证

❌ **禁止**：
- 商业用途

💡 **适用场景**：
- 学术论文、研究成果
- 教育资源
- 协作式学术创作

**示例标注**：
```
本作品采用CC BY-NC-SA 4.0协议
仅允许非商业用途
改编作品必须用相同许可证
```

---

### 6. CC BY-NC-ND（署名-非商业-禁止演绎）
**最严格的许可证**

✅ **允许**：
- 非商业使用
- 原样复制和分发

❌ **禁止**：
- 商业用途
- 任何形式的改编

💡 **适用场景**：
- 个人原创作品
- 不希望被修改或商用
- 最强保护级别

**示例标注**：
```
本作品采用CC BY-NC-ND 4.0协议
仅允许非商业用途
禁止改编或修改
```

## 四、许可证选择决策树

### 如何选择合适的CC许可证？

```
问题1：是否允许商业使用？
├─ 是 → 继续问题2
└─ 否 → CC BY-NC系列

问题2：是否允许改编/修改？
├─ 是 → 继续问题3
└─ 否 → CC BY-ND系列

问题3：改编作品是否要求相同许可？
├─ 是 → CC BY-SA
└─ 否 → CC BY

最终选择：
1. 允许一切 → CC BY（最宽松）
2. 商用+改编+相同许可 → CC BY-SA
3. 商用+禁止改编 → CC BY-ND
4. 非商业+改编 → CC BY-NC
5. 非商业+改编+相同许可 → CC BY-NC-SA
6. 非商业+禁止改编 → CC BY-NC-ND（最严格）
```

## 七、使用CC素材的法律风险

### 常见违规场景

#### ❌ 错误1：未署名
```javascript
// CC BY素材但未注明来源
const image = "https://unsplash.com/photo/123" // CC BY
使用方式：直接使用，未标注来源
风险：违反署名要求，侵权
```

#### ❌ 错误2：商业使用NC素材
```javascript
// CC BY-NC素材用于商业项目
const素材 = "教育图片" // CC BY-NC
使用场景：付费课程、商业广告
风险：违反非商业条款，侵权
```

#### ❌ 错误3：改编ND素材
```javascript
// CC BY-ND素材进行修改
const素材 = "官方声明" // CC BY-ND
操作：翻译、缩略、改编
风险：违反禁止演绎条款，侵权
```

#### ❌ 错误4：改编SA素材未用相同许可
```javascript
// CC BY-SA素材改编后用严格许可
const原素材 = "Wikipedia内容" // CC BY-SA
改编后许可：CC BY-NC-ND（更严格）
风险：违反相同方式共享条款，侵权
```

## 九、实操案例

### 案例1：AI生成剧本使用CC素材

**场景**：
- 用AI写剧本
- 剧本中使用了Wikipedia背景资料（CC BY-SA）
- 剧本商用付费

**合规操作**：
```
剧本创作流程：
1. 使用一鉴到底记录创作过程
2. 素材来源：Wikipedia（CC BY-SA）
3. 标注要求：
   - 在剧本注明："背景资料来源：Wikipedia CC BY-SA"
4. 许可证要求：
   - 剧本本身必须采用CC BY-SA（因为改编了SA素材）
5. 商用：
   - ✅ 允许（CC BY-SA允许商用）

结论：合规，但剧本需用CC BY-SA
```

### 案例2：视频制作使用NC素材

**场景**：
- 制作商业视频
- 使用了某艺术家的音乐（CC BY-NC）

**合规判断**：
```
素材检测：
- 音乐来源：艺术家个人网站
- 许可证：CC BY-NC
- 商用：❌ 禁止

风险分析：
- 商业视频 = 商业用途
- 使用NC素材 = 违规
- 法律风险：侵权赔偿

解决方案：
1. 联系艺术家购买商业授权
2. 或更换为CC0/CC BY音乐
3. 或改为非商业视频

一鉴到底提示：
⚠️ 高风险：该素材禁止商业使用！
建议：更换素材或联系作者授权
```

## 十、常见问题FAQ

### Q1：AI生成内容用CC素材，版权怎么算？

**A**：
```
AI生成内容版权判定：
1. 纯AI生成 = 无版权
2. 人+AI共创 = 人工部分有版权
3. AI改编CC素材：
   - 必须遵守素材原许可
   - 改编部分可能无版权（纯AI）
   - 人工修改部分有版权

建议：使用一鉴到底记录创作过程
证明：人工创作部分 + 遵守素材许可
```

### Q2：不知道素材许可证怎么办？

**A**：
```
未知许可证素材处理：
1. 查找来源平台
   - Unsplash/Pexels → CC0（安全）
   - Wikipedia → CC BY-SA（需遵守）
   - 其他 → 查看标注或联系作者

2. 使用一鉴到底素材风险报告
   - 自动检测素材来源
   - 标注风险等级
   - 生成使用建议

3. 高风险素材
   - ❌ 不要使用
   - ✅ 联系作者确认
   - ✅ 更换为明确许可的素材
```

### Q3：CC许可证版本差异？

**A**：
```
CC许可证版本：
1. CC 1.0 - 最初版本（已过时）
2. CC 2.0 - 增加法律条款
3. CC 3.0 - 国际化完善
4. CC 4.0 - 当前最新版本（推荐）

建议：使用CC 4.0版本
原因：
- 更完善的法律保护
- 国际通用标准
- 多语言支持（45+语言）
```
