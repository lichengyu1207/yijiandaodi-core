**Firefox适配**：
```javascript
// 统一API封装
const browserAPI = (() => {
  if (typeof chrome !== 'undefined') return chrome;  // Chrome/Edge
  else if (typeof browser !== 'undefined') return browser;  // Firefox
})();

// 使用示例
browserAPI.storage.local.get('key');
```

## 十一、已知限制

### 11.1 技术限制

| 限制 | 原因 | 解决方案 |
|------|------|---------|
| **不支持桌面应用** | 浏览器插件限制 | 使用Web版平台 |
| **无法录制桌面操作** | 安全策略限制 | 仅录制浏览器内操作 |
| **部分平台内容捕获受限** | 跨域/加密限制 | 记录URL而非内容 |
| **离线时间戳无NTP同步** | 网络限制 | 标注"离线模式" |

---

### 11.2 平台限制

| 平台 | 限制 | 影响 |
|------|------|------|
| **chrome://页面** | 安全策略禁止 | 无法录制浏览器设置页 |
| **chrome扩展商店** | 安全策略禁止 | 无法录制扩展管理页 |
| **银行/支付页面** | 安全策略限制 | 部分功能受限 |
| **加密页面** | 内容无法捕获 | 仅记录URL |
