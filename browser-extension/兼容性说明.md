# 浏览器兼容性说明

## 支持的浏览器

### ✅ 完全支持

**Chrome**
- 版本要求：88+（Manifest V3）
- 安装方式：开发者模式加载
- 文件：`manifest.json`

**Edge (Chromium内核)**
- 版本要求：88+（Manifest V3）
- 安装方式：开发者模式加载
- 文件：`manifest.json`

### ⚠️ 需要调整

**Firefox**
- 版本要求：78+
- 需要使用：`manifest-firefox.json`
- 安装方式：
  1. 重命名 `manifest-firefox.json` 为 `manifest.json`
  2. 加载到Firefox

**Safari**
- 需要转换为Safari Web Extension
- 使用Xcode打包

---

## API兼容性

### 已实现兼容层

所有浏览器API已通过`browserAPI`统一封装：

```javascript
const browserAPI = (() => {
  if (typeof chrome !== 'undefined') {
    return chrome; // Chrome/Edge
  } else if (typeof browser !== 'undefined') {
    return browser; // Firefox
  }
})();
```

### 兼容的API

| 功能 | Chrome/Edge | Firefox |
|------|-------------|---------|
| 存储 | browserAPI.storage.local | ✓ |
| 消息 | browserAPI.runtime.sendMessage | ✓ |
| 标签页 | browserAPI.tabs.query | ✓ |
| 脚本注入 | browserAPI.scripting.executeScript | ✓ |
| 定时器 | browserAPI.alarms | ✓ |

## 功能兼容性

### ✅ 所有浏览器都支持

- 操作记录
- 指纹生成
- 证据链导出
- 时间戳显示
- 平台识别
- 浮动窗口

### ⚠️ 注意事项

**Firefox特殊处理**
- 不支持`browserAPI.scripting`，需要使用`tabs.executeScript`
- Manifest V2格式
- 需要`applications.gecko.id`

## 安装指南

### Chrome/Edge安装

```
1. 打开 chrome://extensions/
2. 开启"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 browser-extension 文件夹
```

### Firefox安装

```
1. 重命名 manifest-firefox.json 为 manifest.json
2. 打开 about:debugging#/runtime/this-firefox
3. 点击"临时加载附加组件"
4. 选择 manifest.json
```

## 已知问题

### Firefox

1. **manifest格式**
   - 必须使用Manifest V2
   - 需要gecko ID

2. **scripting API**
   - 不支持`browserAPI.scripting`
   - 需要使用`tabs.executeScript`

### Safari

需要转换为Safari Web Extension格式。
