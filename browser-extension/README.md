# 一鉴到底浏览器插件

## 功能说明

记录操作 + 本地存指纹 + 一键导出证据链报告

### 核心功能

1. **操作记录**
   - 文本输入/编辑
   - 图片上传/选择
   - 文件上传
   - 复制/粘贴/剪切
   - 保存/提交操作
   - AI生成/检测操作

2. **本地指纹存储**
   - 五元组联合哈希算法（SHA-256）
   - 五元组：操作指令 + 校验结果 + 确认凭证 + 时间戳 + 前次指纹
   - 哈希碰撞率为零
   - 数据存储在浏览器本地，不出域

3. **一键导出报告**
   - HTML格式证据链报告
   - 包含操作时间线
   - 包含指纹证据链
   - 司法级不可篡改

## 安装方法

### Chrome浏览器

1. 打开Chrome，访问 `chrome://extensions/`
2. 开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"
4. 选择 `browser-extension` 文件夹
5. 插件图标出现在浏览器工具栏

### Edge浏览器

1. 打开Edge，访问 `edge://extensions/`
2. 开启左下角"开发人员模式"
3. 点击"加载解压缩的扩展"
4. 选择 `browser-extension` 文件夹
5. 插件图标出现在浏览器工具栏

## 使用方法

1. **开始记录**
   - 点击插件图标打开弹窗
   - 点击"开始记录"按钮
   - 状态指示器变绿，表示正在记录

2. **创作过程**
   - 正常使用AI工具（如ChatGPT、文心一言等）
   - 插件自动记录所有操作
   - 实时生成不可篡改指纹

3. **停止记录**
   - 点击"停止记录"按钮
   - 会话自动保存到本地

4. **导出报告**
   - 点击"一键导出证据链报告"
   - 下载HTML格式报告
   - 报告包含完整的时间线和指纹链

## 技术架构

```
browser-extension/
├── manifest.json          # 插件配置（Manifest V3）
├── background/
│   └── background.js      # 后台服务（指纹生成、存储管理）
├── content/
│   ├── content.js         # 内容脚本（操作记录）
│   └── content.css        # 样式
├── popup/
│   ├── popup.html         # 弹窗界面
│   └── popup.js           # 弹窗控制
└── icons/
    ├── icon16.png
    ├── icon32.png
    ├── icon48.png
    └── icon128.png
```

## 隐私保护

- ✅ 所有数据存储在浏览器本地
- ✅ 不上传任何内容到服务器
- ✅ 文本内容仅保留前200字符预览
- ✅ 敏感信息自动脱敏
- ✅ 用户可随时删除数据
