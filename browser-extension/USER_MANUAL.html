产品简介

🎯 一鉴是什么？

一鉴到底 是一款专业的创作过程记录工具，帮助用户：

  • ✅ 记录完整创作过程 - 自动记录所有 AI 对话、文本输入、图片生成等操作
  • ✅ 生成可信证据链 - 使用五元组哈希链算法，确保记录不可篡改
  • ✅ 跨平台支持 - 支持 25+ 创作平台，包括 DeepSeek、ChatGPT、文心一言等
  • ✅ 云端同步 - 数据自动同步到云端，永不丢失
  • ✅ 导出专业报告 - 一键生成包含时间戳、指纹链的完整报告

🔐 核心价值

功能 价值
原创证明 证明作品是您亲自创作的，而非 AI 直接生成
版权保护 完整的创作过程记录，可作为版权证据
账号备份 即使账号被封，作品证明仍在您手中
跨平台管理 统一管理多个平台的创作记录

安装指南

步骤 1: 下载插件

从以下渠道获取插件：

  1. 官方网站: https://yijiandaodi.com/extension
  2. Chrome 商店: 搜索"一鉴到底"
  3. 本地安装: 从项目目录加载

步骤 2: 安装到浏览器

Chrome / Edge 用户：

  1. 打开浏览器，访问：
    chrome://extensions/
  2. 开启右上角的 "开发者模式"
  3. 点击 "加载已解压的扩展程序"
  4. 选择插件目录：
    c:\MsSafeData\Desktop\yijiandaodi\browser-extension
  5. 安装成功！您将在工具栏看到插件图标

快速开始

💡 重要提示: 本插件支持免登录使用！您可以直接开始录制，无需注册账号。

5 分钟上手指南

步骤 1: 开始录制（无需登录）

  1. 点击 "▶ 开始记录" 按钮
  2. 右上角将出现悬浮窗，显示：
    • 当前时间（国家授时中心）
    • 录制状态
    • 操作计数
    • 识别的创作平台

步骤 3: 进行创作

现在您可以：

  • 访问 DeepSeek、ChatGPT 等 AI 平台进行对话
  • 使用剪映、即梦等工具进行创作
  • 在 WPS、Photoshop 中编辑文档

所有操作都会被自动记录！

步骤 4: 停止录制

  1. 点击悬浮窗中的 "停止录制" 按钮
  2. 或点击插件图标 → "停止录制"

步骤 5: 导出报告

  1. 点击悬浮窗中的 "导出报告" 按钮
  2. 选择报告格式（PDF / JSON）
  3. 报告将自动下载到您的电脑

步骤 6: 申请原创声明（需登录）

如果您需要获取原创声明证书：

  1. 点击 "登录" 按钮，登录您的账号
  2. 登录后，点击 "申请原创声明" 按钮
  3. 填写作品标题，选择作品类型
  4. 选择已有的会话记录，或直接粘贴作品内容
  5. 点击 "提交审核"
  6. 等待管理员审核（通常 1-3 个工作日）
  7. 审核通过后，下载 原创声明证书
💡 原创声明证书 包含：声明编号、作品信息、哈希指纹、签发时间等，可作为原创证明使用。

功能详解

1️⃣ 录制功能

开始录制

点击"开始记录"后，插件会：

  1. 创建新的录制会话
  2. 生成唯一会话 ID
  3. 开始监控页面操作
  4. 显示悬浮窗

录制内容

插件会记录以下操作：

操作类型 说明 示例
AI 提示词 您输入给 AI 的问题 "帮我写一篇文章..."
AI 回复 AI 生成的回复内容 "好的，以下是文章..."
文本输入 在编辑器中输入的文字 WPS 文档内容
图片生成 AI 生成的图片 即梦/Midjourney 生成的图片
复制/粘贴 复制粘贴操作 复制文本内容
保存/导出 保存或导出文件 导出 PDF

防抖机制

为避免频繁记录，插件使用 3 秒防抖：

  • 同类型操作在 3 秒内只记录一次
  • 自动合并相似操作
  • 减少无效记录

拖拽功能

  • 拖拽方式: 点击蓝色标题栏，按住拖拽
  • 边界保护: 不会拖出屏幕外
  • 位置记忆: 下次打开保持在同一位置

3️⃣ 云端同步

登录状态

状态 说明
☁️ 云同步已开启 所有录制自动同步到云端
☁️ 云同步未开启 登录后可开启云同步

离线支持

如果网络断开：

  1. 数据继续保存在本地
  2. 网络恢复后自动同步
  3. 不会丢失任何记录

4️⃣ 证据链生成

五元组哈希链

每个操作生成一个指纹：

指纹 = SHA-256(操作类型 + 操作数据 + 时间戳 + 前序指纹 + 时间来源)

证据链结构

操作1 → 指纹1 (prevHash: 0)
           ↓
操作2 → 指纹2 (prevHash: 指纹1)
           ↓
操作3 → 指纹3 (prevHash: 指纹2)
           ↓
        ...

时间来源

可信时间戳来自：

  • 国家授时中心: ntp.ntsc.ac.cn
  • 精度: 毫秒级
  • 不可篡改: 每个指纹包含时间戳

5️⃣ 原创声明（需登录）

功能介绍

原创声明是为您的作品提供官方认证的功能。审核通过后，您将获得：

  • 声明编号: 唯一的认证编号（如 YJDD-20260713-A1B2C3D4）
  • 原创证书: 可下载的 HTML 格式证书
  • 公开验证: 任何人可通过编号验证真伪

申请流程

  1. 登录账号 - 必须登录后才能申请
  2. 点击"申请原创声明" - 打开申请表单
  3. 填写信息:
    • 作品标题（必填）
    • 作品类型（AI对话、文章、图片、代码等）
    • 选择会话记录 或 直接粘贴内容
  4. 提交审核 - 等待管理员审核
  5. 审核通过 - 生成声明编号，下载证书

证书内容

字段 说明
声明编号 格式: YJDD-YYYYMMDD-XXXXXXXX
作品标题 您填写的作品名称
作者 您的用户名
作品类型 AI对话/文章/图片/代码等
内容哈希 SHA-256 指纹，确保内容不可篡改
签发时间 审核通过的时间
验证链接 yijiandaodi.com/verify/{声明编号}

验证证书

任何人都可以验证证书真伪：

  1. 访问 yijiandaodi.com/verify/{声明编号}
  2. 系统会显示证书信息和内容哈希
  3. 对比证书上的哈希值是否一致

常见问题

Q1: 录制会影响浏览器性能吗？

A: 不会。插件经过深度优化：

  • 使用防抖机制，避免频繁记录
  • 页面不可见时暂停 UI 更新
  • 智能合并相似操作
  • 异步处理，不阻塞页面

Q2: 数据会丢失吗？

A: 不会。多重保护机制：

  • 本地存储：数据保存在浏览器
  • 云端同步：登录后自动同步到服务器
  • 离线支持：断网时继续本地保存
  • 恢复机制：重新加载插件时自动恢复状态

Q3: 支持哪些浏览器？

A: 目前支持：

  • ✅ Chrome 90+
  • ✅ Edge 90+
  • ✅ Firefox 88+
  • ⏳ Safari（计划中）

Q4: 如何证明作品是我创作的？

A: 完整的证据链：

  1. 每个操作都有时间戳
  2. 时间来自国家授时中心
  3. 五元组哈希链不可篡改
  4. 任何修改都会导致指纹链断裂

Q5: 跨平台录制如何工作？

A: 无缝切换：

  1. 在 DeepSeek 开始录制
  2. 切换到豆包，悬浮窗自动更新
  3. 切换到 WPS，继续记录
  4. 所有操作合并到一个会话
  5. 导出包含所有平台的完整报告

Q6: 悬浮窗可以移动吗？

A: 可以！

  • 点击蓝色标题栏拖拽
  • 位置自动记忆
  • 不会拖出屏幕外

Q7: 如何查看历史录制？

A: 两种方式：

  1. 本地查看: 点击插件图标 → 历史记录
  2. 云端查看: 登录后台 yijiandaodi.com/my-sessions

Q8: 数据安全吗？

A: 完全安全：

  • 数据加密传输（HTTPS）
  • JWT Token 认证
  • 数据隔离，只属于您
  • 符合隐私保护法规
