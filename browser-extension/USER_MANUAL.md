## 产品简介

### 🎯 一鉴是什么？

**一鉴到底** 是一款专业的创作过程记录工具，帮助用户：

- ✅ **记录完整创作过程** - 自动记录所有 AI 对话、文本输入、图片生成等操作
- ✅ **生成可信证据链** - 使用五元组哈希链算法，确保记录不可篡改
- ✅ **跨平台支持** - 支持 25+ 创作平台，包括 DeepSeek、ChatGPT、文心一言等
- ✅ **云端同步** - 数据自动同步到云端，永不丢失
- ✅ **导出专业报告** - 一键生成包含时间戳、指纹链的完整报告

### 🔐 核心价值

| 功能 | 价值 |
|------|------|
| **原创证明** | 证明作品是您亲自创作的，而非 AI 直接生成 |
| **版权保护** | 完整的创作过程记录，可作为版权证据 |
| **账号备份** | 即使账号被封，作品证明仍在您手中 |
| **跨平台管理** | 统一管理多个平台的创作记录 |

## 安装指南

### 步骤 1: 下载插件

从以下渠道获取插件：

1. **官方网站**: [https://yijiandaodi.com/extension](https://yijiandaodi.com/extension)
2. **Chrome 商店**: 搜索"一鉴到底"
3. **本地安装**: 从项目目录加载

### 步骤 2: 安装到浏览器

#### Chrome / Edge 用户：

1. 打开浏览器，访问：
   ```
   chrome://extensions/
   ```

2. 开启右上角的 **"开发者模式"**

3. 点击 **"加载已解压的扩展程序"**

4. 选择插件目录：
   ```
   c:\MsSafeData\Desktop\yijiandaodi\browser-extension
   ```

5. 安装成功！您将在工具栏看到插件图标

#### Firefox 用户：

1. 访问 `about:addons`
2. 点击齿轮图标 → "安装附加组件"
3. 选择插件的 `.xpi` 文件

## 快速开始

### 5 分钟上手指南

#### 步骤 1: 登录账号

1. 点击浏览器工具栏中的插件图标
2. 点击 **"登录"** 按钮
3. 输入您的用户名和密码
4. 点击 **"登录并开启同步"**

> 💡 **提示**: 您也可以选择"暂不登录"，数据将仅保存在本地

#### 步骤 2: 开始录制

1. 点击 **"▶ 开始记录"** 按钮
2. 右上角将出现悬浮窗，显示：
   - 当前时间（国家授时中心）
   - 录制状态
   - 操作计数
   - 识别的创作平台

#### 步骤 3: 进行创作

现在您可以：

- 访问 DeepSeek、ChatGPT 等 AI 平台进行对话
- 使用剪映、即梦等工具进行创作
- 在 WPS、Photoshop 中编辑文档

所有操作都会被自动记录！

#### 步骤 4: 停止录制

1. 点击悬浮窗中的 **"停止录制"** 按钮
2. 或点击插件图标 → **"停止录制"**

#### 步骤 5: 导出报告

1. 点击悬浮窗中的 **"导出报告"** 按钮
2. 选择报告格式（PDF / JSON）
3. 报告将自动下载到您的电脑

## 功能详解

### 1️⃣ 录制功能

#### 开始录制

点击"开始记录"后，插件会：

1. 创建新的录制会话
2. 生成唯一会话 ID
3. 开始监控页面操作
4. 显示悬浮窗

#### 录制内容

插件会记录以下操作：

| 操作类型 | 说明 | 示例 |
|----------|------|------|
| AI 提示词 | 您输入给 AI 的问题 | "帮我写一篇文章..." |
| AI 回复 | AI 生成的回复内容 | "好的，以下是文章..." |
| 文本输入 | 在编辑器中输入的文字 | WPS 文档内容 |
| 图片生成 | AI 生成的图片 | 即梦/Midjourney 生成的图片 |
| 复制/粘贴 | 复制粘贴操作 | 复制文本内容 |
| 保存/导出 | 保存或导出文件 | 导出 PDF |

#### 防抖机制

为避免频繁记录，插件使用 **3 秒防抖**：

- 同类型操作在 3 秒内只记录一次
- 自动合并相似操作
- 减少无效记录

### 2️⃣ 悬浮窗

#### 显示内容

```
┌─────────────────────────────────────┐
│  一鉴到底  🤖 DeepSeek       [−] [×]│  ← 拖拽标题栏移动
├─────────────────────────────────────┤
│         🕐 14:30:45                 │  ← 国家授时中心时间
│          2026/06/01                 │
│      来源: 国家授时中心              │
├─────────────────────────────────────┤
│  ● 正在录制                         │  ← 录制状态
├─────────────────────────────────────┤
│    5       12       15              │  ← 统计数据
│  操作数  创作内容  指纹数            │
├─────────────────────────────────────┤
│  识别平台: 🤖 DeepSeek              │  ← 当前平台
├─────────────────────────────────────┤
│   [停止录制]    [导出报告]           │  ← 操作按钮
└─────────────────────────────────────┘
```

#### 拖拽功能

- **拖拽方式**: 点击蓝色标题栏，按住拖拽
- **边界保护**: 不会拖出屏幕外
- **位置记忆**: 下次打开保持在同一位置

#### 最小化/关闭

- **最小化 [−]**: 悬浮窗收缩为小图标
- **关闭 [×]**: 隐藏悬浮窗（录制继续）

### 3️⃣ 云端同步

#### 登录状态

| 状态 | 说明 |
|------|------|
| ☁️ 云同步已开启 | 所有录制自动同步到云端 |
| ☁️ 云同步未开启 | 登录后可开启云同步 |

#### 同步流程

```
浏览器插件                     云端服务器
    │                              │
    │ ── 开始录制 ───────────────>│ 创建会话记录
    │                              │
    │ ── 操作记录（实时） ────────>│ 保存操作详情
    │                              │
    │ ── 停止录制 ───────────────>│ 更新会话状态
    │                              │
    │ ── 导出报告 ───────────────>│ 生成完整报告
```

#### 离线支持

如果网络断开：

1. 数据继续保存在本地
2. 网络恢复后自动同步
3. 不会丢失任何记录

### 4️⃣ 证据链生成

#### 五元组哈希链

每个操作生成一个指纹：

```
指纹 = SHA-256(操作类型 + 操作数据 + 时间戳 + 前序指纹 + 时间来源)
```

#### 证据链结构

```
操作1 → 指纹1 (prevHash: 0)
           ↓
操作2 → 指纹2 (prevHash: 指纹1)
           ↓
操作3 → 指纹3 (prevHash: 指纹2)
           ↓
        ...
```

#### 时间来源

可信时间戳来自：

- **国家授时中心**: ntp.ntsc.ac.cn
- **精度**: 毫秒级
- **不可篡改**: 每个指纹包含时间戳

### 5️⃣ 报告导出

#### PDF 报告内容

1. **会话信息**
   - 会话 ID
   - 开始/结束时间
   - 总操作数
   - 总指纹数

2. **操作详情**
   - 每个操作的时间、类型、内容预览
   - 对应的平台信息

3. **证据链**
   - 完整的指纹链
   - 每个指纹的哈希值
   - 时间戳来源

4. **统计图表**
   - 操作类型分布
   - 平台使用比例
   - 时间线图

## 常见问题

### Q1: 录制会影响浏览器性能吗？

**A**: 不会。插件经过深度优化：

- 使用防抖机制，避免频繁记录
- 页面不可见时暂停 UI 更新
- 智能合并相似操作
- 异步处理，不阻塞页面

### Q2: 数据会丢失吗？

**A**: 不会。多重保护机制：

- 本地存储：数据保存在浏览器
- 云端同步：登录后自动同步到服务器
- 离线支持：断网时继续本地保存
- 恢复机制：重新加载插件时自动恢复状态

### Q3: 支持哪些浏览器？

**A**: 目前支持：

- ✅ Chrome 90+
- ✅ Edge 90+
- ✅ Firefox 88+
- ⏳ Safari（计划中）

### Q4: 如何证明作品是我创作的？

**A**: 完整的证据链：

1. 每个操作都有时间戳
2. 时间来自国家授时中心
3. 五元组哈希链不可篡改
4. 任何修改都会导致指纹链断裂

### Q5: 跨平台录制如何工作？

**A**: 无缝切换：

1. 在 DeepSeek 开始录制
2. 切换到豆包，悬浮窗自动更新
3. 切换到 WPS，继续记录
4. 所有操作合并到一个会话
5. 导出包含所有平台的完整报告

### Q6: 悬浮窗可以移动吗？

**A**: 可以！

- 点击蓝色标题栏拖拽
- 位置自动记忆
- 不会拖出屏幕外

### Q7: 如何查看历史录制？

**A**: 两种方式：

1. **本地查看**: 点击插件图标 → 历史记录
2. **云端查看**: 登录后台 yijiandaodi.com/my-sessions

### Q8: 数据安全吗？

**A**: 完全安全：

- 数据加密传输（HTTPS）
- JWT Token 认证
- 数据隔离，只属于您
- 符合隐私保护法规
