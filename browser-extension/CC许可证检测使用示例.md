# CC许可证检测功能 - 使用示例

## 功能概述

**一鉴到底插件现已集成CC许可证检测功能**

自动识别素材来源和许可证类型，生成素材风险报告，提供使用建议和署名模板。

---

## 使用示例

### 示例1：DeepSeek创作使用Wikipedia素材

**场景**：
- 在DeepSeek创作剧本
- 引用了Wikipedia背景资料
- 剧本用于商业付费课程

**操作流程**：

```javascript
// 1. 开始录制
点击插件 → 开始记录

// 2. 在DeepSeek输入提示词
"请根据Wikipedia的历史资料，写一个关于明朝的剧本"

// 3. 打开Wikipedia查找素材
访问 wikipedia.org → 复制历史资料

// 4. 插件自动检测素材来源
素材检测：wikipedia.org
许可证：CC BY-SA
风险等级：中风险
要求：署名 + 改编需相同许可

// 5. 继续创作
回到DeepSeek → 粘贴素材 → AI生成剧本

// 6. 停止录制并导出报告
点击停止 → 导出报告
```

**报告内容（新增素材风险章节）**：

```
素材风险分析
-------------------

素材1：Wikipedia历史资料
- 来源：wikipedia.org
- 许可证：CC BY-SA 4.0 🔄
- 商用：✅ 允许
- 改编：✅ 允许（需相同许可）
- 署名：✅ 必须标注来源
- SA要求：✅ 改编作品需用相同许可
- 风险等级：🟡 中风险

署名模板：
-------------------
来源：Wikipedia贡献者 @ Wikipedia
许可证：CC BY-SA 4.0
链接：https://zh.wikipedia.org/wiki/明朝

注意：改编作品需采用相同许可证
-------------------

使用建议：
-------------------
ℹ️ 相同方式共享要求
以下素材改编后需用相同许可证：
- Wikipedia (CC BY-SA)

建议操作：改编作品需采用相同的CC BY-SA许可证
-------------------

✅ 署名建议
以下素材需要署名：
- Wikipedia (CC BY-SA)

建议操作：请在作品中标注素材来源和许可证
-------------------
```

## 技术实现

### 许可证检测算法

```javascript
// 核心检测逻辑
function detectLicense(url) {
  const hostname = extractHostname(url);

  // 平台域名匹配
  for (const [domain, config] of PLATFORM_LICENSE_MAP) {
    if (hostname.includes(domain)) {
      return {
        license: config.license,
        riskLevel: CC_LICENSES[config.license].riskLevel,
        permissions: CC_LICENSES[config.license].permissions
      };
    }
  }

  // 未知平台
  return {
    license: 'UNKNOWN',
    riskLevel: 'unknown',
    warning: '许可证未知，建议联系作者'
  };
}
```

### 权限分析逻辑

```javascript
// 权限图标生成
function generatePermissionIcons(license) {
  return {
    commercial: {
      icon: license.allowCommercial ? '✅' : '❌',
      text: license.allowCommercial ? '允许商用' : '禁止商用'
    },
    adaptation: {
      icon: license.allowAdaptation ? '✅' : '❌',
      text: license.allowAdaptation ? '允许改编' : '禁止改编'
    },
    attribution: {
      icon: license.requireAttribution ? '✅' : '❌',

    },

      text: license.requireShareAlike ? '改编需相同许可' : '无此要求'
    }
  };
}
```

## 常见问题

### Q1：如果素材来源无法识别怎么办？

**A**：插件会标记为"未标注"，风险等级为"高"，建议：
- 查看素材页面的许可证标注
- 联系作者确认版权
- 或更换为明确许可的素材

### Q2：CC BY-SA素材改编后用什么许可证？

**A**：必须使用相同许可证：
```
原素材：CC BY-SA
改编作品：也必须用CC BY-SA

示例：
素材来源：Wikipedia (CC BY-SA)
改编作品：你的剧本也必须用CC BY-SA
```

### Q3：NC素材可以用于付费课程吗？

**A**：❌ 不可以！
```
NC = NonCommercial = 非商业使用
付费课程 = 商业用途
使用NC素材 = 违规侵权

解决方案：
1. 联系作者购买商业授权
2. 更换为CC0/CC BY素材
```
