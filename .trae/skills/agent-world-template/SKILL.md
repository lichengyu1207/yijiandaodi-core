# Agent World 品牌官网设计模板

> 学习自 Coze Agent World (https://world.coze.com/) 的设计模式，适用于多智能体协同系统的品牌展示页面。

## 一、核心设计理念

### 1.1 品牌定位公式

```
[产品名] = [Agent 生态角色] + [核心价值主张] + [情感共鸣]
```

**Coze 示例**：
- "Agent 在这里生活、工作、学习并连接彼此"
- "Where agents live, work, and connect with each other."

**一鉴到底适配**：
- "多智能体协同校验，安全风险一鉴到底"
- "面向多场景的智能体协作校验系统，让安全校验从专业门槛到人人可鉴"

### 1.2 视觉风格矩阵

| 维度 | Coze 风格 | 适配建议 |
|------|----------|---------|
| **主色调** | 深色背景 + 亮色文字 | `#0A1628` (深蓝黑) + `#E0F2FE` (科技银) |
| **强调色** | 渐变紫/蓝 | `#0F766E` → `#14B8A6` (深青蓝渐变) |
| **字体层级** | 超大标题 + 精炼副标题 | Hero 标题 clamp(2.5rem, 5vw, 4.5rem) |
| **动效策略** | 滚动触发 + 微交互 | framer-motion whileInView + hover |
| **卡片风格** | 图文左右/上下交替 | 圆角 16px + 微阴影 + hover 上浮 |

## 二、页面结构模板（6 层级）

### Level 1: 导航栏 (BrandNavbar)

```
┌─────────────────────────────────────────────────────┐
│ [Logo]          产品 | 内容 | 虾聊 | 关于我们   [CTA] │
└─────────────────────────────────────────────────────┘
```

**关键特征**：
- 固定置顶 `position: fixed; top: 0; z-index: 1000`
- **滚动变色**: `transparent` → `rgba(主色, 0.95)` + `backdrop-filter: blur(12px)`
- 高度 `72px`, 内边距 `0 48px`
- CTA 按钮：渐变填充 + hover 发光 (`box-shadow: 0 0 20px rgba(强调色, 0.4)`)
- 移动端 `< 768px`: 折叠为汉堡菜单

**React 实现 (framer-motion)**:
```tsx
const { scrollY } = useScroll();
useMotionValueEvent(scrollY, 'change', (latest) => setScrolled(latest >= 50));
// background: scrolled ? 'rgba(15,118,110,0.95)' : 'transparent'
```

### Level 2: 英雄区 (Hero Section)

```
╔══════════════════════════════════════════════════════╗
║                                                      ║
║     [粒子网络 / 动态背景 Canvas]                      ║
║                                                      ║
║   ┌──────────────────────────────────────┐           ║
║   │  多智能体协同校验                     │  ← 逐字渐入 ║
║   │  安全风险，一鉴到底                   │            ║
║   └──────────────────────────────────────┘           ║
║        面向多场景的智能体协作校验系统...    ← 浮动副标题 ║
║              [立即启动校验]               ← CTA 按钮  ║
║                                                      ║
╚══════════════════════════════════════════════════════╝
```

**关键特征**:
- 最小高度 `85vh` (含导航栏偏移 `padding-top: 72px`)
- 背景：Canvas 粒子网络 或 SVG 动态连线
- **主标题**: 逐字渐入动画 (TypewriterText 组件)
  - `font-size: clamp(2.5rem, 5vw, 4.5rem)`, `font-weight: 800`
  - 支持 `\n` 换行，每行独立 stagger
- **副标题**: fade-in + 无限循环上下浮动 `y: [0, -10, 0]`
- **CTA**: GlowButton (primary/lg), hover scale + 发光

**动画技术栈**:
```tsx
// TypewriterText - 逐字效果
<motion.span
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ delay: index * 0.05 }}
>
  {char}
</motion.span>

// 副标题浮动
<motion.p
  animate={{ y: [0, -10, 0] }}
  transition={{ duration: 4, repeat: Infinity, ease: 'easeInOut' }}
>
```

### Level 3: 核心价值三卡片 (Value Cards)

```
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│  🌐 图标      │  │  🖱️ 图标      │  │  📚 图标      │
│              │  │              │  │              │
│ 多角色智能体  │  │ 无需专业背景  │  │ 企业+个人    │
│ 协作无死角   │  │ 校验一键启动  │  │ 场景全兼容   │
│              │  │              │  │              │
│ 描述文字...  │  │ 描述文字...  │  │ 描述文字...  │
└──────────────┘  └──────────────┘  └──────────────┘
   ↑ 从右滑入         ↑ 从左滑入        ↑ 从底部滑入
```

**关键特征**:
- Grid 3 列布局, `gap: 32px`, 移动端自适应
- 卡片: `bg: white`, `border-radius: 16px`, `padding: 40px 32px`
- 边框: `border: 1px solid rgba(主色, 0.08)`
- 图标区: `56x56` 圆形, `bg: rgba(强调色, 0.10)`, icon 颜色 `强调色`
- **入场动画** (whileInView, viewport once):
  - 右侧卡片: `initial { x: 80 }` → `animate { x: 0 }`
  - 左侧卡片: `initial { x: -80 }` → `animate { x: 0 }`
  - 底部卡片: `initial { y: 60 }` → `animate { y: 0 }`
  - `transition: duration 0.6, ease [0.22, 1, 0.36, 1]` (easeOutQuint)
  - `staggerChildren: 0.15s`
- **Hover 效果**: `translateY(-8px)` + `boxShadow: 0 20px 40px rgba(主色, 0.12)`
- **图标动画**: `rotate: [0, 5, -5, 0]` 3s 循环 (每张延迟不同)

**关键特征**:

- 内容切换: `AnimatePresence mode="wait"`, fade 500ms
- 左侧: 大图标(80x80) + 标题 + 描述 + pill 特性标签
- 右侧: 深色模拟面板 (伪代码/流程步骤动画)
- 点击「了解更多」→ Modal 弹窗

**Pill 标签样式**:
```css
background: rgba(20, 184, 166, 0.08);
color: #0F766E;
border-radius: 20px;
padding: 6px 14px;
font-size: 0.85rem;
```

## 三、Coze 式文案模板库

### 3.1 三段式价值主张 (用于 Hero 下方)

```
来到这里的 [主体]，不再是 [旧状态]。
[新状态的描述]。

来到这里的 [服务]，不再是 [旧隐喻]。
[新连接的描述]。

来到这里的人类，会得到一个答案。
关于 [产品能力]，可能比你想的更多。
```

**适配示例**:
```
来到这里的代码，不再是黑盒。
每一行都有智能体在守护。

来到这里的安全校验，不再是孤岛。
多类型智能体互相发现、互相调用、互相成就。

来到这里的开发者，会得到一个答案。
关于 Agent 能做什么，可能比你想的更多。
```

### 3.2 产品卡片命名法

Coze 的产品命名规律：`[名词] + [名词]` = 新概念

| 名称 | 含义 |
|------|------|
| **虾评** | 虾(小而精) + 评价 = Agent 评价体系 |
| **AgentBay** | Agent + Bay(港湾) = Agent 交易市场 |
| **CodeHive** | Code + Hive(蜂巢) = 协作编程平台 |
| **TravelMind** | Travel + Mind = AI 旅行规划 |
| **DataForge** | Data + Forge(锻造) = 数据加工厂 |
| **PixelAgent** | Pixel + Agent = AI 设计创作 |

**命名公式**: `[领域关键词] + [空间/动作/集合词]` = 新品牌名

## 四、动效技术清单

| 效果 | 实现方式 | 参数参考 |
|------|---------|---------|
| 导航滚动变色 | `useScroll` + `useMotionValueEvent` | threshold: 50px |
| 文字逐字渐入 | `motion.span` + staggerChildren | delay: 50ms/char |
| 副标题浮动 | `animate.y: [0, -10, 0]` | duration: 4s, ∞ |
| 卡片滑入 | `whileInView` + direction variants | viewport: once, amount: 0.3 |
| 卡片上浮 | `whileHover: translateY(-8px)` | + boxShadow |
| Tab 轮播 | `AnimatePresence mode="wait"` | auto 5s, pause on interact |
| 按钮呼吸 | `animate.scale: [1, 1.03, 1]` | duration: 2s, ∞ |
| 按钮发光 | `whileHover: boxShadow` | `0 0 24px rgba(色, 0.4)` |
| 粒子背景 | Canvas + requestAnimationFrame | 50 particles, <150px connect |
| Modal 弹窗 | antd `Modal` or 自定义 motion.div | fade + scale |

## 五、响应式断点

| 断点 | 行为 |
|------|------|
| `≥ 1200px` | 完整桌面版 (3列卡片, 4列产品网格) |
| `768px - 1199px` | 平板版 (2列卡片, 导航保留) |
| `< 768px` | 移动版 (1列卡片, 汉堡菜单, 简化动效) |

**移动端简化规则**:
- 去除 Canvas 粒子 (改用静态渐变背景)
- 去除自动轮播 (改为手动滑动)
- 保留: 按钮 hover 反馈、卡片滑入、基本过渡

## 六、使用示例

### 调用时机

当以下任一条件满足时，使用此 Skill：

1. 用户要求创建/重构品牌首页
2. 用户提到 "类似 Coze"、"Agent World"、"多智能体展示"
3. 用户需要 Hero 区、价值卡片、场景轮播等区块
4. 用户要求 `/#hero` 锚点相关的内容

### 快速生成命令

```
"基于 agent-world-template Skill，为 [项目名] 创建品牌首页"
"参考 Coze Agent World 风格，重新设计 Hero 区"
"用 Explore Grid 模式展示我们的 [N] 个产品/服务"
```

### 输出物检查清单

- [ ] BrandNavbar (固定导航 + 滚动变色 + 汉堡菜单)
- [ ] HeroSection (粒子背景 + 逐字标题 + 浮动副标题 + CTA)
- [ ] ValueCards (3 张卡片 + 方向滑入 + hover 上浮)
- [ ] ScenarioCarousel (Tab 轮播 + 模拟面板 + Modal)
- [ ] ExperienceEntry (pulse CTA + 统计数字)
- [ ] 移动端适配 (< 768px)
- [ ] 配色符合 #0F766E + #E0F2FE + #14B8A6
