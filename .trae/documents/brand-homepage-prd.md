# 一鉴到底 - 品牌官网首页 PRD

## 1. 产品概述

**一鉴到底（YiJianDaoDi）** 是面向多智能体协同的校验系统品牌官网。将原有的信息流首页升级为品牌展示型官网，同时将原信息流内容迁移至导航栏「Agent 执行中心」入口，实现「品牌形象 → 产品体验」的清晰转化路径。

- **核心价值**: 多智能体协同校验，让安全风险一键可鉴
- **目标用户**: 企业安全团队、个人开发者、内容审核从业者
- **市场定位**: 国内首个多智能体协作的安全校验平台

## 2. 核心功能模块

### 2.1 用户角色

| 角色 | 核心权限 | 核心场景 |
|------|---------|---------|
| 访客 | 浏览官网、体验 Demo | 了解产品、触发 CTA |
| 注册用户 | 完整功能使用 | 进入 Agent 执行中心 |
| 企业用户 | 团队协作 + 合规审计 | 企业级安全校验 |

### 2.2 功能模块清单

1. **品牌导航栏**: 固定置顶、滚动渐变背景、Logo + 四导航项 + CTA 按钮
2. **英雄区 (Hero Section)**: 主标题逐字动画 + 智能体粒子联动背景 + CTA 按钮
3. **核心价值三卡片**: 多智能体协同 / 零门槛操作 / 全场景适配
4. **场景演示轮播**: 企业团队 / 个人开发者 / 合规审计 三场景动态切换
5. **体验入口板块**: 强引导 CTA + 呼吸动效按钮
6. **原信息流迁移**: 迁移至「Agent 执行中心」导航入口

### 2.3 页面详情

| 页面区域 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 顶部固定区 | BrandNavbar | Logo「一鉴到底」+ 导航「产品/协同场景/立即校验/关于我们」+ CTA「免费体验」，滚动时透明→深青蓝渐变 |
| 首屏视觉冲击区 | HeroSection | 主标题"多智能体协同校验\n安全风险，一鉴到底"(逐字渐入) + 副标题(淡入浮动) + CTA「立即启动校验」(hover 放大+波纹反馈) + 背景：智能体节点粒子网络 + 数据流动画 |
| 第二屏 | ValueCards (3张) | 卡片1: 多角色智能体协作无死角(右侧滑入)；卡片2: 零门槛一键启动(左侧滑入)；卡片3: 企业+个人全兼容(底部滑入)，hover 上浮+阴影放大 |
| 第三屏 | ScenarioCarousel | 三场景轮播：企业团队协作 / 个人开发者校验 / 合规审计场景，自动切换淡入淡出，点击展开详情弹窗 |
| 第四屏 | ExperienceEntry | 大尺寸 CTA「立即进入校验系统」+ 说明文字 + 按钮呼吸动效 |

## 3. 核心流程

```
访客访问首页 → 浏览 Hero 区(粒子动画吸引注意)
    ↓ 滚动浏览 → 核心价值三卡片(联动滑入动画)
    ↓ 继续滚动 → 场景演示轮播(交互沉浸)
    ↓ 到达底部 → 点击「立即进入校验系统」CTA
    ↓ 跳转路径 A → /execution-center (Agent 执行中心 = 原信息流)
    ↓ 跳转路径 B → /login (未登录时引导注册)
```

## 4. 界面设计规范

### 4.1 设计风格

| 设计元素 | 规范值 |
|---------|-------|
| **主色调** | 深青蓝 `#0F766E`（传递多智能体协同感） |
| **辅助色** | 科技银 `#E0F2FE`（科技感高亮） |
| **强调色** | 亮青 `#14B8A6`（CTA 按钮、链接） |
| **背景色** | 深色 `#0A1628`（Hero 区域）→ 渐变至浅色 `#FAFBFC`（下方区域） |
| **文字色** | 主文字 `#1E293B`，次要 `#64748B`，反白 `#FFFFFF` |
| **字体** | 标题：思源黑体 Bold / 正文：系统默认 sans-serif |
| **按钮风格** | 圆角 8px，CTA 使用渐变填充(#0F766E→#14B8A6)，hover 外发光效果 |
| **图标风格** | Lucide 图标 + 自定义 SVG 智能体节点图标 |
| **布局风格** | 全宽容器 + 居中内容区(max-width:1200px)，卡片式分区 |

### 4.2 各区块 UI 规格

| 区块 | 布局 | 关键尺寸 | 动画规格 |
|------|------|---------|---------|
| BrandNavbar | 全宽 fixed, 高度 72px | 内容 max-width:1200px 居中 | scroll>50px: bg透明→rgba(15,118,110,0.95), backdrop-blur; hover: 按钮外发光 #E0F2FE |
| HeroSection | 全宽, min-height:85vh | 标题 font-size: clamp(2.5rem,5vw,4.5rem) | 文字逐字 stagger 50ms; 粒子 Canvas requestAnimationFrame; CTA hover scale(1.05)+box-shadow glow |
| ValueCards | 三列 grid, gap:32px | 单卡 min-width:320px, padding:40px | 卡片 whileInView: slide-in(左右下); hover: translateY(-8px)+shadow-xl; 图标循环闪烁 |
| ScenarioCarousel | 全宽, 3个tab切换 | 内容区 max-width:1000px | 自动轮播 5s; 切换 fade 500ms; 点击 expand modal |
| ExperienceEntry | 居中, padding:80px 0 | CTA 按钮 font-size:1.25rem, padding:16px 48px | 呼吸动画 scale(1→1.03) 2s 循环; click: ripple + 跳转 |

### 4.3 响应式设计

| 断点 | 导航 | Hero | 价值卡片 | 场景演示 | 体验入口 |
|------|------|------|---------|---------|---------|
| ≥1200px (Desktop) | 完整水平导航 | 全尺寸粒子+大标题 | 3列并排 | 3 tab 横排 | 大按钮居中 |
| 768-1199px (Tablet) | 保持水平，字号缩小 | 粒子简化 | 2列+1行 | 2 tab + 横滚 | 中等按钮 |
| <768px (Mobile) | 汉堡菜单 | 无粒子，精简文案 | 单列竖排 | 单卡片竖滑 | 全宽按钮 |

## 5. 路由与导航调整

| 变更项 | 变更前 | 变更后 |
|--------|--------|--------|
| `/` 路由 | Home 组件(信息流) | BrandHome 组件(品牌官网) |
| FrontHeader NAV_ITEMS | `[首页, 关于我们]` | `[产品, 协同场景, 立即校验(#hero), 关于我们]` + CTA「免费体验」 |
| 「Agent 执行」按钮 | 跳转 `/agent` | 跳转 `/execution-center`(原 Home 信息流内容) |
| 新增路由 | 无 | `/` → BrandHome; 原 Home 内容保留在组件中供 execution-center 复用 |
