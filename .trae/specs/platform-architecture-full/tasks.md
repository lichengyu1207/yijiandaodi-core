# Tasks

## Phase 1：基础底座（当前阶段）✅ 已完成

- [x] **Task 1: 主网页版 Home 老骇心法UI重做** [2天]
  - [x] 1.1 首页Hero区域重构
    - 当前：复杂的多模块信息流布局
    - 目标：「输入框 + 单能力卡片」极简布局（文档8.2节）
    - 输入框居中大字体，placeholder: "说一句话，开始智能检测"
    - 支持语音/拖拽上传/粘贴图片文本
  - [x] 1.2 单能力卡片组件标准化
    - 每个卡片只有3元素：标题 + 老骇式提示数据 + 执行按钮
    - 卡片列表：论文检测 | 代码执行 | 文本安全 | 数据泄露 | OCR | 更多
    - 颜色规范：黑白红三色系
  - [x] 1.3 信息流区域保留但降级
    - 现有信息流内容保留不动（用户明确要求不改首页信息流）
    - 但新增「快速入口」区域在输入框下方

- [x] **Task 2: ASS输入层巡检前端实现** [1.5天]
  - [x] 2.1 输入校验中间件
    - 创建 `frontend/src/middleware/inputGuard.ts`
    - Prompt注入检测：正则匹配指令覆盖/系统提示词泄露模式
    - 敏感词过滤：内置多级敏感词库（政治/色情/暴力/违法违规）
    - 恶意指令拦截：rm -rf /、格式化磁盘、下载恶意软件等
    - 输入长度/类型/格式严格校验
  - [x] 2.2 巡检结果UI反馈
    - 高危：红色弹窗拦截，官方化提示语
    - 中危：黄色警告条，脱敏后放行确认
    - 低危：静默记录，不影响使用

- [x] **Task 3: ASS输出层巡检前端实现** [1天]
  - [x] 3.1 结果脱敏引擎
    - 创建 `frontend/src/utils/dataMask.ts`
    - 正则+NLP识别：手机号/身份证/银行卡/邮箱/企业机密
    - 自动替换为 *** 脱敏格式
    - 显示脱敏统计：「已自动保护 X 条敏感信息」
  - [x] 3.2 输出签名验证
    - 签名校验结果完整性（简化实现，生产环境用RSA）
    - 异常结果自动标记并提示重新执行

- [x] **Task 4: 统一结果页模板（老骇心法）** [1.5天]
  - [x] 4.1 创建通用 ResultCard 组件
    - 第一行固定：「✅ 检测任务已完成」或风险等级横幅
    - 核心指标区：数字+大白话，不用技术术语
    - 行动按钮区：唯一主按钮（下载报告/重新检测）
  - [x] 4.2 详细分析折叠区
    - 默认收起，点击展开
    - 包含：各维度详细数据/改进建议/安全日志摘要
  - [x] 4.3 各单能力页面迁移到统一模板 ✅
    - Originality → 统一结果页 ✅
    - Grammarly → 统一结果页 ✅
    - Copyscape → 统一结果页 ✅
    - ResumeOptimizer → 统一结果页（保留雷达图等特色）✅

- [x] **Task 5: Agent执行中心升级为编排层入口** [2天]
  - [x] 5.1 新增意图识别模块
    - 基于关键词+规则引擎判断用户意图类别
    - 分类：安全检测 / 文本处理 / 代码执行 / 办公自动化 / 多媒体
    - 自动路由到对应技能页面或执行流程
  - [x] 5.2 新增任务原子化拆解
    - 复杂需求→多步骤原子任务列表
    - 示例："帮我检测并优化这篇论文" → [AI检测] + [重复率检测] + [优化建议]
  - [x] 5.3 新增执行状态可视化
    - 七层流转进度条（应用层→编排层→ASS→路由→算力→执行→审计）
    - 每层显示耗时和状态

- [x] **Task 6: 免费额度与强筛选机制** [1天]
  - [x] 6.1 使用次数限制器
    - 前端本地计数 + 后端校验双重保障
    - 免费版：每天10次
    - 达到限额时显示会员引导
  - [x] 6.2 会员状态展示
    - 导航栏显示：积分余额 / 会员等级 / 到期时间
    - 个人中心页面：会员权益对比表
