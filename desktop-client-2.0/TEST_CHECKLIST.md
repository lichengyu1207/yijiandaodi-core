## 🐛 常见问题

### Q1：桌宠不显示？

**检查**：
```bash
# 查看控制台是否有错误
# 应该显示：[系统] ✅ 桌宠窗口创建成功
```

---

### Q2：Dashboard 没有记录？

**检查**：
1. 控制台是否显示：`[剪贴板监控] ✅ 记录保存成功`
2. 打开 DevTools（F12）查看错误
3. 确认文件存在：`C:\Users\Administrator\AppData\Roaming\一鉴到底\data\operations.json`

---

### Q3：进程监控不工作？

**可能原因**：
- 需要管理员权限
- 应用名称不匹配

**解决方案**：
以管理员身份运行应用

---

### Q4：网络监控不准确？

**可能原因**：
- HTTPS 加密
- DNS 解析问题

**解决方案**：
- 使用进程监控补充
- 检查特定域名

### 进程监控

## 🎯 性能建议

- **剪贴板**：500ms 是推荐值，太快会影响性能
- **进程**：5s 比较合适，太快会产生大量日志
- **网络**：10s 足够，太快会占用系统资源
