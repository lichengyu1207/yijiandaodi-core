## 🔍 问题排查

### 问题1：污点未创建

**可能原因**：
- 文件内容未达到检测阈值
- 监控服务未启动

**解决方法**：
```bash
# 检查是否有以下日志
[系统] ✅ 文件监控已启动
[系统] ✅ 剪贴板监控已启动
[系统] ✅ 污点追踪已初始化
```

---

### 问题2：污点检测失败

**可能原因**：
- 内容哈希不匹配（内容变化）
- 污点数量超过限制（10,000）

**解决方法**：
```bash
# 检查污点统计
# 控制台应输出：
[污点追踪] 统计: { taintCount: X, propagationCount: Y }
```

---

### 问题3：告警未触发

**可能原因**：
- 风险等级低于阈值
- 频率控制生效

**解决方法**：
