# Skill 接入能力快速验证指南

**目标**: 快速判断其他用户能否正常接入平台 skill

---

## 🚀 3 分钟快速验证

### 方法1: 检查平台文档

**步骤**：
```
1. 登录平台官网
2. 查找 "开发者文档" 或 "API 文档"
3. 查找 "Skill" 或 "技能" 相关章节
```

**判断标准**：
- ✅ **找到文档** → Skill 可接入，继续查看接入方式
- ❌ **未找到文档** → 可能不可接入，需要进一步确认

---

### 方法2: 询问平台管理员

**直接询问**：
```
问题1: 平台的 skill 是否提供 HTTP API？
问题2: 其他用户能否在自己的应用中调用 skill？
问题3: 是否有接入文档和示例代码？
问题4: 是否需要付费？如何定价？
```

---

### 方法3: 运行测试脚本

**前提条件**：
```powershell
# 已安装 Node.js
node --version  # >= 14.0

# 有平台的 API Key（如果有）
```

**运行测试**：
```powershell
# 1. 修改配置
# 编辑 test-skill-integration.js
# 更新 API_BASE_URL 和 API_KEY

# 2. 运行
node test-skill-integration.js
```

**结果解读**：

| 测试结果 | 说明 | 建议 |
|---------|------|------|
| ✅ HTTP 200 | API 可用 | 可以接入 |
| ❌ HTTP 401 | 需要认证 | 获取 API Key |
| ❌ HTTP 404 | 端点不存在 | Skill 未提供 API |
| ❌ DNS 失败 | 地址错误 | 检查 API 地址 |
| ❌ 连接拒绝 | 服务未启动 | 联系管理员 |

## 🎯 根据结果行动

### 情况1: API 可用 ✅

**接入步骤**：
```
1. 获取 API Key
2. 阅读 API 文档
3. 调用测试脚本验证
4. 集成到自己的应用
5. 监控和优化
```

**示例代码**：
```javascript
// 调用 code-detector skill
const response = await fetch('https://api.yijiandaodi.com/v1/skills/code-detector', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    code: 'eval(userInput)',
    language: 'javascript'
  })
})

const result = await response.json()
console.log(result)
```

### 情况2: API 不可用 ❌

**替代方案**：

#### 方案A: 对话式调用（临时）
```
适用场景：
- 临时检测
- 小规模使用
- 测试验证

限制：
- 无法编程调用
- 不适合生产环境
- 无法批量处理
```

#### 方案B: 自己实现（推荐）
```
优势：
- 完全可控
- 无外部依赖
- 可定制化

参考：
- 本项目的实现方式
- electron/monitoring/autoDetector.ts
- electron/securityKnowledgeBase.ts

工作量：
- 基础功能：1-2 天
- 完整功能：1 周
```

#### 方案C: 等待平台支持（长期）
```
建议：
- 向平台提需求
- 参与功能投票
- 关注更新公告
```

## 🔍 详细验证流程

```markdown

### 1. 文档检查
- [ ] 找到平台官网

- [ ] 有调用权限

### 4. 功能检查
- [ ] code-detector 可用
- [ ] content-moderator 可用
- [ ] sandbox-executor 可用
- [ ] 其他需要的 skill 可用

### 5. 稳定性检查
- [ ] 响应时间合理（< 2s）
- [ ] 成功率高（> 99%）
- [ ] 有错误处理
- [ ] 有技术支持

### 6. 成本检查
- [ ] 定价合理
```
