# 一鉴到底隐私政策

**生效日期：2025年1月1日**

「一鉴到底」开发团队（以下简称"我们"）深知个人信息对您的重要性，我们将按照法律法规要求，采取相应安全保护措施，尽力保护您的个人信息安全可控。

---

## 一、我们收集的信息

### 1.1 身份信息（实名认证需要）
- 手机号码（用于实名认证）
- 姓名（用于出具审计报告时的身份确认）

### 1.2 本地数据
以下数据**仅存储在您的本地设备**，我们无法访问：
- AI Agent 操作日志
- 风险分析记录
- 审计存证报告
- 系统配置信息

---

## 二、信息使用目的

### 2.1 身份信息使用
- 完成实名认证
- 在导出的审计报告中标注出具人身份
- 确保报告的法律效力

### 2.2 本地数据处理
所有分析处理均在您的本地设备完成，数据不离开您的设备。

---

## 三、信息存储与保护

### 3.1 存储位置
- **身份数据**：加密存储于安全服务器
- **业务数据**：存储于用户本地设备（我们无法访问）

### 3.2 安全措施
- 采用 HTTPS 加密传输
- 采用行业标准加密算法存储
- 定期进行安全审计

### 3.3 数据保留
- 身份数据：账户注销后30天内删除
- 业务数据：由用户自行管理，可随时删除

---

## 四、您的权利

### 4.1 访问权
您可以随时查看、导出您的数据。

### 4.2 更正权
您可以随时更正您的个人信息。

### 4.3 删除权
您可以随时删除您的本地数据。账户注销后，我们将删除您的身份数据。

### 4.4 卸载权
本软件可以被彻底卸载，不留残留文件或注册表项。

---

## 五、实名认证特别说明

### 5.1 认证目的
实名认证是为了：
- 确保审计报告的出具人身份可追溯
- 提升报告的法律证据效力
- 防止恶意滥用

### 5.2 数据隔离原则
- 身份数据不上传到业务系统
- 校验行为不绑定身份（仅在导出报告时关联）
- 本地日志不包含身份信息

### 5.3 认证方式
我们采用以下方式完成实名认证：
- 微信小程序认证（获取已实名手机号）
- 或手机号 + 验证码认证

---

## 六、数据不出境特别声明

### 6.1 服务部署
- 桌面端应用：部署在用户本地设备
- API 服务：部署在用户本地设备
- DeepSeek API：使用国内服务器

### 6.2 数据存储
- 所有业务数据存储在用户本地设备
- 不传输到境外服务器
- 如使用境外服务，将明确告知用户并获得同意

### 6.3 第三方服务
本软件调用 DeepSeek API 进行智能分析：
- DeepSeek API 服务器位于国内
- 仅发送操作内容和上下文描述
- 不发送用户身份信息
- API 调用遵循 DeepSeek 隐私政策

### 6.4 本地大模型
支持使用 Ollama 等本地模型：
- 数据完全不出域
- 不涉及任何云端服务

## 七、未成年人保护

我们不为未满18周岁的未成年人提供服务。如果您是未成年人，请勿使用本软件。

我们可能适时修订本隐私政策。修订后的政策将在官方网站公布。
