# 一鉴到底法律合规声明

**六大红线承诺**

---

## 红线一：不触碰隐私内容

我们**只分析操作的"行为特征"**，不读取具体内容：

| 我们分析 | 我们不触碰 |
|---------|-----------|
| 操作类型（如：修改配置文件） | 文件具体内容 |
| 执行命令名称 | 聊天记录内容 |
| 风险行为特征 | 邮件正文 |
| 操作时间、来源 | 个人文件内容 |

**技术实现：**
- 我们只提取操作命令的名称和参数数量
- 不读取文件内容、不解析文档正文
- 不分析聊天记录、邮件内容

---

## 红线二：不替用户做决定

我们**只提供风险提醒和建议**，最终决定权100%归用户：

- 我们输出：风险等级、分析解释、操作建议
- 用户决定：确认放行 或 取消拦截
- 我们不做：自动执行任何拦截或放行操作

**界面明确声明：**
> "本工具仅提供辅助性分析，最终决定权归用户"

---

## 红线三：不传输原始数据

所有敏感数据**只存在用户本地**：

| 数据类型 | 存储位置 | 是否上传 |
|---------|---------|---------|
| 操作日志 | 用户本地 | 否 |
| 风险分析结果 | 用户本地 | 否 |
| 审计报告 | 用户本地 | 否 |
| 配置信息 | 用户本地 | 否 |

**云端仅存储：**
- 不可还原的哈希值摘要（用于验证数据完整性）
- 匿名化的统计数据（用于产品优化）

---

## 红线四：不开源许可证违规

我们使用的主要开源组件：

| 组件 | 许可证 | 合规状态 |
|------|--------|---------|
| Electron | MIT | ✓ |
| React | MIT | ✓ |
| Vite | MIT | ✓ |
| Python | PSF | ✓ |
| DeepSeek API | 商业授权 | ✓ |

所有开源组件均保留原始许可证声明。

---

## 红线五：不做虚假宣传

我们不使用以下绝对化词汇：
- ❌ "100%安全"
- ❌ "绝对可靠"
- ❌ "零风险"
- ❌ "完全防护"

我们如实说明：
- 误报率：<5%（基于测试数据）
- 召回率：>95%（基于测试数据）
- 覆盖范围：常见风险操作类型
- 局限性：无法覆盖所有未知风险

---

## 红线六：数据不出境

| 服务 | 部署位置 | 合规状态 |
|------|---------|---------|
| 桌面端 | 用户本地 | ✓ |
| API 服务 | 用户本地 | ✓ |
| DeepSeek API | 国内服务器 | ✓ |
| 数据存储 | 用户本地 | ✓ |

如使用境外服务，将在《隐私政策》中明确告知。
