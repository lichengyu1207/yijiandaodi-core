## 📊 版本对比

### 极简版（推荐）
- ✅ **自动播放**：无需点击
- ✅ **旋转展开动效**：Z轴+Y轴旋转

- ✅ **爆炸粒子**：出场冲击感

## 💡 使用建议

### 首次查看

**推荐流程：**
1. 查看极简版（最炫酷的动效）
2. 查看React组件版本（实际集成）
3. 阅读集成指南
4. 选择合适的版本集成

### 实际使用

**官网首页集成：**
```tsx
// frontend/src/pages/Home/index.tsx
import LogoAnimation from '@/components/LogoAnimation';

const Home = () => {
  const [showLogoAnimation, setShowLogoAnimation] = useState(true);
  
  useEffect(() => {
    const timer = setTimeout(() => {
      setShowLogoAnimation(false);
    }, 5000);
    return () => clearTimeout(timer);
  }, []);

  return (
    <div>
      {showLogoAnimation && <LogoAnimation />}
      {/* 原有内容 */}
    </div>
  );
};
```

### 演示展示

**使用HTML版本：**
- 打开 `animations/启动Logo动画演示.bat`
- 选择合适的版本
- 全屏展示效果更好

## 🔧 自定义修改

### 修改颜色

```css
/* 主色调 */
--primary-color: #165DFF;  /* 蓝色 */
--secondary-color: #00D4FF; /* 科技蓝 */
--background: #000000;     /* 深色背景 */
```

### 修改尺寸

```css
.logo-img {
  width: 200px;  /* Logo宽度 */
  height: 200px; /* Logo高度 */
}

.title {
  font-size: 68px; /* 标题大小 */
}
```

### 修改动画速度

```css
.logo-img {
  animation-duration: 0.8s; /* Logo动画时长 */
}

.title {
  animation-delay: 2s; /* 标题延迟时间 */
}
```
