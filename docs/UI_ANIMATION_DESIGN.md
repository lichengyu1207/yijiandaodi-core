## 二、动画设计方案

### 2.1 Logo动画

#### 2.1.1 Logo变形动画

**设计理念：**
从"锁"到"盾牌"再到"AI大脑"的演变，展示产品从安全保护到智能检测的核心理念。

**动画流程：**
```
阶段1（0-1秒）：锁头图标淡入
阶段2（1-2秒）：锁头旋转并变形为盾牌
阶段3（2-3秒）：盾牌上出现AI神经网络图案
阶段4（3-4秒）：图案发光，周围环绕数据流
```

**技术参数：**
- 帧率：60fps
- 时长：4秒
- 分辨率：1920x1080
- 格式：MP4/WebM
- 文件大小：约2MB

**颜色方案：**
- 主色：#165DFF（品牌蓝）
- 辅色：#00D4FF（科技蓝）
- 高光：#FFFFFF（白色）
- 背景：#0A0E1A（深色背景）

#### 2.1.2 Logo微动效

**设计理念：**
Logo在静止状态下的微动效，增加生命力和科技感。

**动画元素：**
1. **呼吸效果：** Logo轻微缩放（0.98-1.02）
2. **光晕流动：** 边缘光晕沿Logo轮廓流动
3. **粒子飘浮：** Logo周围有微小粒子飘浮

**技术实现：**
```css
.logo-container {
  animation: breathe 3s ease-in-out infinite;
}

.logo-glow {
  animation: glowFlow 5s linear infinite;
}

.logo-particle {
  animation: particleFloat 10s linear infinite;
}

@keyframes breathe {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.02); }
}
```

### 2.2 核心功能演示动画

#### 2.2.1 代码安全检测动画

**设计理念：**
展示AI如何智能检测代码中的安全漏洞。

**动画场景：**
```
场景1：代码编辑器界面
场景2：AI扫描波纹覆盖代码
场景3：发现漏洞，标记高亮显示
场景4：AI给出修复建议
场景5：代码自动修复
```

**动画脚本：**

**第1秒：**
- 代码编辑器从左侧滑入
- 显示一段包含漏洞的代码

**第2-3秒：**
- AI扫描波纹从顶部向下流动
- 扫描波纹颜色：蓝色渐变到青色
- 波纹经过处代码轻微发光

**第4秒：**
- 发现安全漏洞，红色警告图标弹出
- 漏洞代码高亮显示（红色背景）
- 警告提示："发现SQL注入风险"

**第5-6秒：**
- AI建议面板从右侧滑入
- 显示修复建议："使用参数化查询"
- 提供修复代码示例

**第7-8秒：**
- 代码自动应用修复
- 修复代码以绿色渐入
- 成功提示："已修复"

**视觉效果：**
- 代码字体：Fira Code（等宽字体）
- 语法高亮：VS Code Dark+主题
- 波纹效果：半透明蓝色，带发光
- 高亮效果：红色/绿色背景 + 边框

#### 2.2.2 内容合规检测动画

**设计理念：**
展示AI如何检测内容中的敏感信息。

**动画场景：**
```
场景1：文档编辑界面
场景2：AI识别敏感内容
场景3：标记并建议修改
场景4：自动脱敏处理
```

**动画脚本：**

**第1秒：**
- 文档编辑器淡入
- 显示包含敏感信息的文档内容

**第2-3秒：**
- AI分析图标出现
- 分析进度条从0%到100%
- 敏感词自动标红

**第4秒：**
- 发现敏感信息，黄色警告标记
- 提示："发现身份证号、手机号"

**第5-6秒：**
- 自动脱敏处理
- 敏感信息被星号替换（138****5678）
- 成功提示："已脱敏"

**视觉效果：**
- 文档样式：类似Word
- 标记颜色：红色（高风险）、黄色（中风险）
- 脱敏效果：渐变动画

#### 2.2.3 多Agent协同检测动画

**设计理念：**
展示多个AI Agent如何协同工作。

**动画场景：**
```
场景1：中心AI大脑
场景2：多个Agent节点连接
场景3：Agent分别执行任务
场景4：结果汇总到中心
场景5：生成综合报告
```

**动画脚本：**

**第1-2秒：**
- 中心AI大脑图标出现
- 发出脉冲信号（同心圆扩散）

**第3-4秒：**
- 6个Agent节点从外围飞入
- 节点类型：代码审计、内容检测、安全扫描、合规检查、性能分析、风险控制
- 每个节点带不同颜色标识

**第5-6秒：**
- Agent节点开始工作
- 各节点显示处理进度
- 数据流从节点流向中心

**第7-8秒：**
- 中心大脑汇聚所有数据
- 数据流汇聚效果（光线聚集）
- 生成综合报告图标

**视觉效果：**
- 节点颜色：红、橙、黄、绿、蓝、紫
- 连接线：半透明发光线条
- 数据流：粒子沿线条流动
- 中心效果：汇聚光芒

### 2.3 交互流程动画

#### 2.3.1 用户使用流程动画

**设计理念：**
展示用户从注册到使用的完整流程。

**流程步骤：**
```
步骤1：用户注册（填写表单动画）
步骤2：邮箱验证（邮件飞入动画）
步骤3：创建项目（文件夹创建动画）
步骤4：上传文件（文件上传进度动画）
步骤5：AI分析（扫描波纹动画）
步骤6：查看报告（报告展开动画）
```

**动画元素：**
- 表单字段逐个填充
- 验证邮件飞入收件箱
- 项目文件夹创建动画
- 文件上传进度条
- AI分析波纹扩散
- 报告页面展开效果

#### 2.3.2 实时监控动画

**设计理念：**
展示实时监控系统的工作状态。

**动画元素：**
1. **数据流动画：** 实时数据流沿路径流动
2. **监控图表动画：** 实时更新的折线图、柱状图
3. **告警动画：** 发现异常时的闪烁和提示
4. **处理动画：** AI自动处理异常的过程

**技术实现：**
- 使用Canvas绑定实时数据
- 数据点动态添加和移除
- 平滑过渡动画
- 告警时颜色变化和脉冲效果

### 2.4 特效动画

#### 2.4.1 粒子系统动画

**应用场景：**
- Logo周围的科技粒子
- 数据流中的数据粒子
- 成功完成时的庆祝粒子

**粒子类型：**
1. **科技粒子：** 小圆点，带发光效果
2. **数据粒子：** 小方块，代表数据包
3. **光芒粒子：** 星星形状，带闪烁效果

**粒子行为：**
- 随机飘浮
- 沿路径流动
- 集中/分散效果
- 生命周期（出现-运动-消失）

#### 2.4.2 波纹扩散动画

**应用场景：**
- AI扫描时的波纹
- 数据传输时的波纹
- 成功提示时的波纹

**波纹效果：**
```
初始状态：小圆点
扩散过程：同心圆向外扩散
最终状态：消失在画面外
```

**技术参数：**
- 扩散速度：200px/s
- 初始半径：10px
- 最大半径：500px
- 透明度：从1到0渐变
- 颜色：品牌蓝色

#### 2.4.3 光效动画

**应用场景：**
- Logo发光效果
- 按钮悬停效果
- 成功完成效果
- 数据传输效果

**光效类型：**
1. **边缘发光：** 沿对象边缘的光晕
2. **内部发光：** 对象内部的亮度变化
3. **投射光芒：** 从一点发出的光线
4. **环境光：** 整体的氛围光照

## 四、技术实现方案

### 4.1 视频动画制作

**工具选择：**
- After Effects：主要动画制作
- Lottie：导出Web动画
- Premiere Pro：视频编辑
- Blender：3D动画（如需要）

**工作流程：**
```
1. 脚本设计 → 2. 分镜绘制 → 3. 动画制作 → 4. 音效合成 → 5. 渲染导出
```

### 4.2 Web动画实现

**技术栈：**
- CSS3 Animations：简单动效
- SVG SMIL：矢量图形动画
- Lottie：复杂动画播放
- Canvas/WebGL：粒子系统和数据可视化
- GSAP：时间轴动画控制

**性能优化：**
- 使用硬件加速（transform, opacity）
- 减少重排重绘
- 使用requestAnimationFrame
- 按需加载动画资源

### 4.3 桌面端动画实现

**技术栈：**
- Electron：桌面应用框架
- HTML5 Canvas：动画渲染
- CSS3 Animations：UI动效
- WebGL：3D效果（如需要）

**集成方案：**
```typescript
// 启动动画
function playSplashAnimation() {
  const splashWindow = new BrowserWindow({
    width: 800,
    height: 600,
    frame: false,
    transparent: true,
    alwaysOnTop: true
  });
  
  splashWindow.loadFile('splash.html');
  
  // 4秒后关闭
  setTimeout(() => {
    splashWindow.close();
    mainWindow.show();
  }, 4000);
}
```
