## 五、清理策略说明

### 5.1 自动清理机制

**Django RotatingFileHandler自动清理**：
- 当文件达到maxBytes时自动轮转
- 当备份数超过backupCount时自动删除最旧文件
- 无需手动干预

---

### 5.2 手动清理场景

**需要手动清理的情况**：
1. **配置变更**：修改了日志策略，需要清理旧文件
2. **异常情况**：日志文件损坏或轮转失败
3. **紧急清理**：磁盘空间不足，需要立即释放空间

---

### 5.3 手动清理方法

**方法1：使用清理脚本**
```bash
python cleanup_logs.py
```

**方法2：手动删除**
```bash
# 进入日志目录
cd backend/logs

# 删除超过30天的备份文件
Get-ChildItem -Filter "*.log.*" | Where-Object {$_.LastWriteTime -lt (Get-Date).AddDays(-30)} | Remove-Item

# 删除所有备份文件（谨慎使用）
Remove-Item *.log.*

# 清空当前日志文件（谨慎使用）
Clear-Content hippocampus.log
```
