## 三、缓存机制说明

### 3.1 缓存策略

**缓存类型**: 内存缓存（Map）

**缓存有效期**: 5分钟

**缓存键生成**:
```typescript
const cacheKey = `long_term_${JSON.stringify(params)}`;
```

---

### 3.2 缓存生命周期

```
第一次查询
  ↓
检查缓存（不存在）
  ↓
从服务器获取数据
  ↓
存入缓存（带时间戳）
  ↓
返回数据

---

第二次查询（5分钟内）
  ↓
检查缓存（存在且未过期）
  ↓
直接返回缓存数据 ✓

---

第二次查询（5分钟后）
  ↓
检查缓存（已过期）
  ↓
从服务器获取数据
  ↓
更新缓存
  ↓
返回数据
```

---

### 3.3 缓存清除

**手动清除**:
```typescript
api.clearCache();
```

**自动清除**:
- 缓存过期（5分钟后）
- 组件卸载时
