## 第一部分 项目核心战略与定位
### 1.1 项目本质定义
一鉴到底不是一个代码执行工具，不是一个安全检测工具，也不是一个AI助手。它是**全球第一个基于端侧闲时异构微算力P2P协同调度与Agent原生安全系统的通用AI任务执行操作系统**。

它解决了当前AI行业三大根本性死穴：
- **安全死穴**：所有大模型生成的内容和代码都存在安全漏洞，没有任何平台为安全兜底
- **成本死穴**：云服务器和GPU推理成本高昂，限制了AI的大规模普及
- **隐私死穴**：用户数据必须上传到云服务器，面临泄露和滥用的风险

### 1.2 核心战略口号
**所有AI生成的内容，所有代码，所有Agent，最终都必须在一鉴到底上安全执行**

### 1.3 三层护城河构建
#### 1.3.1 安全护城河（不可复制）
- ASS全链路安全内核，所有任务必经四层安全巡检，无任何旁路
- 零信任执行模型，默认不信任任何代码、任何节点、任何用户
- 安全保险兜底机制，经ASS校验的任务出问题平台全额赔付
- 操作全程白盒化，全链路不可篡改日志，支持执行回放和司法取证

#### 1.3.2 成本护城河（云厂商永远打不过）
- EIHM-P2P-CS算力网络，利用全球闲置算力，执行成本为传统云的1/20
- 前端TF推理引擎，利用用户浏览器GPU进行AI推理，成本趋近于零
- 无硬件空置成本，无服务器运维成本，无带宽成本（P2P传输）
- 动态定价机制，闲时算力价格自动降低，忙时自动调节供需

#### 1.3.3 生态护城河（网络效应）
- 1000+场景原子技能库，覆盖所有用户需求
- 社区技能市场，开发者上传技能获得分成
- 多端插件生态，集成所有主流IDE和大模型平台
- 节点激励体系，用户贡献算力获得积分，形成病毒式增长

### 1.4 与OpenAI的战略关系
我们不是OpenAI的竞争对手，而是OpenAI的**基础设施和安全合作伙伴**。
- OpenAI负责生成最好的代码和内容
- 我们负责让这些代码和内容安全、低成本、合规地执行
- 用户可以继续使用任何大模型，但必须通过我们的平台执行
- 所有大模型最终都将成为我们的"内容生成插件"

### 1.5 老骇心法在项目中的全面落地
老骇心法是项目的灵魂，所有产品设计、技术实现、运营策略都必须严格遵循以下原则：
1. **不教育用户，只筛选用户**：不做圣母，只服务愿意为安全和效率付费的用户
2. **不讲道理，只讲后果**：所有提示都用大白话和数字，不用技术术语
3. **0阅读，0决策**：用户只需要说一句话，剩下的全部交给我们
4. **强筛选，过滤白嫖党**：免费用户有严格的额度限制，高级功能只对付费用户开放
5. **出事我扛**：所有安全责任由平台承担，给用户绝对的安全感

### 3.2 核心设计原则
1. **安全第一**：ASS是所有任务的唯一入口，没有任何旁路，任何任务必须经过全链路安全校验
2. **数据不出域**：用户原始数据永远留在用户本地，只传输加密后的任务指令和结果
3. **成本最优**：优先使用前端TF推理节点，其次是桌面客户端节点，最后是自营节点
4. **操作透明**：所有操作100%可追溯、可回放、可审计，没有黑盒
5. **弹性无限**：全球端侧设备都是我们的算力节点，理论上算力无限
6. **轻量极速**：所有前端页面首屏加载<1s，响应时间<100ms
7. **老骇心法**：所有用户交互都遵循0阅读、0决策、强筛选、出事兜底的原则

## 第四部分 ASS全链路安全内核深度实现
### 4.1 ASS核心定位
ASS（Agent Security System）是整个架构的**心脏和唯一入口**，所有用户请求、技能调用、代码执行、P2P任务调度必须经过ASS，没有任何旁路直通。它实现了从输入到输出的全生命周期安全防护，彻底解决Agent安全问题。

### 4.2 四层安全巡检机制（自动触发，用户无感）
#### 4.2.1 输入层巡检（防护目标：恶意Prompt、越权指令、脏数据注入）
**巡检对象**：用户Prompt、指令、上传文件、API入参、技能调用参数
**巡检内容**：
- Prompt注入攻击：指令覆盖、系统提示词泄露、角色扮演绕过
- 恶意指令：删除文件、格式化磁盘、执行系统命令、下载恶意软件
- 敏感词：政治敏感、色情暴力、恐怖主义、违法违规内容
- 越权请求：访问未授权的资源、执行超出权限的操作
- 脏数据注入：恶意文件伪装、病毒木马、SQL注入、XSS攻击

**技术实现**：
1. **规则引擎**：基于正则表达式和语义规则的精准拦截，内置10万+条规则，每天自动更新
2. **大模型语义风控**：使用自研大模型对用户输入进行语义分析，识别模糊的恶意意图
3. **敏感词库**：内置多级敏感词库，支持自定义敏感词和白名单
4. **文件杀毒引擎**：集成ClamAV开源引擎+自研病毒特征库，对所有上传文件做全盘扫描
5. **输入格式校验**：严格校验输入参数的格式、长度、类型，防止畸形输入攻击

**量化指标**：
- 拦截率≥99.9%
- 误判率≤0.1%
- 单次巡检耗时≤10ms
- 支持1000QPS并发

**处置逻辑**：
- 高危：直接拦截，返回老骇式提示："老骇拦你一下！这个操作会搞崩你的电脑，别瞎搞"
- 中危：脱敏后放行，记录审计日志
- 低危：静默记录，不影响用户使用

#### 4.2.2 静态层巡检（防护目标：恶意代码、漏洞依赖、后门木马）
**巡检对象**：AI生成代码、用户上传代码、社区技能脚本、依赖包、可执行文件
**巡检内容**：
- 代码漏洞：SQL注入、XSS、CSRF、路径遍历、命令注入、硬编码密钥
- 恶意依赖：带有漏洞、后门、挖矿程序的第三方依赖包
- 后门代码：远程控制、数据窃取、权限提升、持久化驻留
- 病毒木马：勒索病毒、挖矿程序、木马程序、间谍软件
- 违规系统调用：rm -rf /、全盘遍历、修改系统配置、访问敏感文件

**技术实现**：
1. **Semgrep代码扫描**：基于AST抽象语法树的代码分析，支持Python、JS、Go、Java等所有主流编程语言，内置5000+条漏洞规则
2. **Trivy依赖扫描**：扫描所有依赖包的已知漏洞，支持npm、pip、maven、gradle等所有包管理器
3. **自研恶意代码特征库**：基于机器学习的恶意代码检测，内置100万+条恶意代码特征
4. **沙箱静态预检测**：在隔离沙箱中静态分析代码的行为，识别潜在的恶意操作
5. **软件成分分析（SCA）**：解析代码的所有依赖组件，检查是否有侵权、违规、恶意组件

**量化指标**：
- 检测覆盖率≥99.99%
- 漏洞检出率≥99.9%
- 误报率≤0.5%
- 单文件扫描速度≥100MB/s

**处置逻辑**：
- 高危漏洞：直接拦截，显示老骇式提示："老骇说：这段代码有SQL注入，执行会拖走你整个数据库，已经帮你拦了"
- 中危漏洞：自动修复，显示提示："老骇已经帮你修复了2个漏洞，可以安全运行了"
- 低危漏洞：静默记录，在审计报告中提示
- 恶意代码：直接拦截，永久拉黑上传者

#### 4.2.3 动态层巡检（防护目标：运行时恶意操作、越权系统调用、资源滥用）
**巡检对象**：任务运行中进程、系统调用、文件读写、网络请求、内存占用、CPU占用
**巡检内容**：
- 异常系统调用：删除系统文件、修改注册表、创建管理员账户、格式化磁盘
- 异常文件操作：全盘遍历、批量删除文件、加密文件、写入恶意内容
- 异常网络访问：连接恶意IP、下载恶意文件、上传敏感数据、端口扫描
- 异常进程行为：创建子进程、注入代码、调试其他进程、隐藏进程
- 资源滥用：占用100%CPU、占用全部内存、大量磁盘IO、大量网络带宽
- 越权操作：访问未授权的文件、执行未授权的系统命令、修改系统配置

**技术实现**：
1. **eBPF系统调用捕获**：基于Linux内核eBPF技术，实时捕获所有系统调用，不需要修改内核

#### 5.4.2 节点生命周期
1. **注册**：节点自动发现并注册到网络，上报硬件配置和网络信息
2. **认证**：平台对节点进行身份认证和安全检测，分配唯一节点ID
3. **心跳**：节点每10秒发送一次心跳，上报实时状态和资源使用率
4. **闲时检测**：实时检测节点的CPU、内存、磁盘、网络使用率
5. **任务执行**：接收平台分发的任务，执行完成后返回结果
6. **激励结算**：根据贡献的算力和时长，自动获得积分奖励
7. **离线**：节点离线后，自动从网络中移除，正在执行的任务自动迁移

### 5.5 闲时检测机制
实时采集节点的以下指标，判断节点是否处于空闲状态：
- CPU使用率：<30%
- 内存使用率：<40%
- 磁盘IO使用率：<20%
- 网络带宽使用率：<30%
- 屏幕状态：屏幕关闭或无操作超过5分钟

**核心规则**：
- 一旦用户本地占用飙升，**100ms内立刻迁移任务、释放算力**，不打扰用户正常使用
- 用户关闭网页或客户端，正在执行的任务自动迁移到其他节点
- 节点连续3次心跳超时，自动标记为离线，任务自动迁移

### 5.6 任务微分片与分布式执行
#### 5.6.1 任务分片策略
将用户的大任务拆分为**≤1MB的微小任务分片**，拆分逻辑遵循以下规则：
1. **数据并行性**：可以并行处理的独立数据块，优先拆分为不同分片
2. **执行解耦性**：将有依赖关系的子任务，按先后顺序拆分，上一个分片执行完成后，再将结果分发到下一个节点
3. **就近原则**：优先将任务分片分发到距离用户物理距离近、网络延迟低的节点
4. **安全原则**：高敏感数据拆分为多个分片，分发到不同地域的节点，单个节点无法获取完整数据

#### 5.6.2 分布式执行流程
1. 智能编排层将大任务拆分为多个微任务分片
2. 成本路由引擎为每个分片选择最优节点
3. 任务分片经过ASS签名后，分发到对应节点
4. 节点执行任务，返回结果和执行日志
5. 结果验证模块对多个节点的结果进行比对
6. 结果聚合模块合并所有分片的结果，生成最终输出
7. 激励结算模块根据节点的贡献，自动发放积分

### 5.7 结果容错与可信校验
**同一份微任务，随机分发到3个**不同地域、不同网络运营商、不同设备架构**的节点并行执行**：
- 2/3结果一致：采信结果，返回用户
- 结果分歧：丢弃异常节点，重新调度可信节点重跑
- 3个结果都不一致：标记任务为异常，人工审核

**恶意节点处置**：
- 第一次返回错误结果：扣除积分，降低信誉评分
- 第二次返回错误结果：临时封禁7天
- 第三次返回错误结果：永久拉入黑名单，不再调度任何任务

### 5.8 成本路由引擎（核心算法）
#### 5.8.1 调度决策因子（加权打分）
| 因子 | 权重 | 说明 |
|------|------|------|
| 算力单位成本 | 40% | 节点的积分/时长价格 |
| 网络延迟 | 25% | 节点与用户之间的网络延迟 |
| 节点历史可靠性 | 20% | 节点的历史执行准确率和在线时长 |
| 任务安全等级 | 10% | 高安全任务只路由高可信节点 |
| 数据地域要求 | 5% | 数据不出域任务只路由指定地域节点 |

#### 5.8.2 目标函数
```
Minimize (成本 * 0.4 + 延迟 * 0.25 + (1 - 可靠性) * 0.2 + 安全风险 * 0.1 + 地域违规 * 0.05)
```

#### 5.8.3 约束条件
1. 节点信用评分≥任务要求的最低信用分
2. 节点的剩余资源≥任务分片需要的资源
3. 节点所在地域符合用户数据不出域的地域要求
4. 预计执行时长≤用户可接受的最长等待时间

### 5.9 NAT穿透与网络优化

### 6.4 模型分片与分布式推理

#### 6.4.2 分布式推理流程

5. 节点之间通过P2P网络传输中间结果
6. 最后一个节点将最终结果返回给用户
7. 平台根据每个节点的贡献，自动发放积分

**优势**：
- 单个节点只需要下载几十MB的模型，不需要下载整个几GB的大模型
- 推理速度随着节点数量的增加线性提升
- 任何节点掉线，自动将任务转移到其他节点，不影响结果
- 数据永远在用户本地和节点之间传输，不上传到平台服务器

### 6.5 浏览器端推理实现
#### 6.5.1 技术选型
- **推理框架**：TensorFlow.js 4.x
- **后端优先**：WebGPU > WebGL > CPU
- **存储**：IndexedDB（模型缓存）
- **并发**：Web Worker（多线程推理，不阻塞主线程）
- **通信**：WebRTC（节点之间P2P通信）

#### 6.5.2 自动成为节点流程
用户打开网页时，后台自动完成以下操作，全程用户无感：
1. 检测浏览器是否支持WebGPU/WebGL
2. 检测GPU型号、显存大小、算力等级
3. 自动注册成为前端TF推理节点
4. 后台自动下载常用模型的基础分片（<10MB）
5. 实时上报节点状态、算力、负载
6. 当有推理任务时，自动参与分布式推理
7. 贡献算力自动获得积分，积分实时显示在页面右上角

#### 6.5.3 性能优化最佳实践
1. **WebGPU加速**：优先使用WebGPU后端，GPU加速比CPU快10倍以上
2. **模型缓存**：使用IndexedDB永久缓存已下载的模型分片，第二次访问秒级启动
3. **内存管理**：使用`tf.tidy()`自动清理张量，防止内存泄漏
4. **批处理**：将多个小任务合并为一个批次执行，提高GPU利用率
5. **跳帧处理**：视频/实时推理任务，每5帧处理一次，降低GPU占用
6. **懒加载**：模型分片按需加载，不提前加载不需要的部分

### 6.6 安全隔离机制
ASS安全内核深度集成到浏览器端，确保前端推理的绝对安全：
1. **模型安全校验**：所有模型分片都经过ASS签名，浏览器只执行经过签名的模型
2. **沙箱隔离**：推理代码运行在浏览器的沙箱中，无法访问用户的本地文件和系统资源
3. **中间结果加密**：节点之间传输的中间结果全部采用AES-256加密，防止数据泄露
4. **结果验证**：同一个推理任务分发到3个不同的节点执行，结果一致才返回
5. **恶意节点检测**：基于行为画像检测恶意节点，自动拉入黑名单

| **用户本地数据**（本地执行日志、缓存、私有技能） | ✅ 100%保留 | 不迁移 | 永久保留 |
| **单能力本地配置**（检测规则、参数模板） | ✅ 100%保留 | 云端同步备份 | 永久保留 |
| **历史执行记录**（本地任务结果、审计日志） | ✅ 100%保留 | 云端增量同步 | 永久保留 |
| **用户账户数据**（会员、积分、权限） | ✅ 保留本地缓存 | 主库迁移到PostgreSQL（双写过渡） | 第30-60天完成双写，第90天切主 |
| **公共技能元数据**（技能列表、描述、参数） | ✅ 保留本地缓存 | 主库迁移到PostgreSQL | 第30-60天完成 |
| **P2P节点数据**（节点状态、算力、信誉） | ❌ 不使用SQLite | 专用分布式KV数据库（TiKV） | 第31天开始新建 |
| **任务分片数据**（任务状态、分片、结果） | ❌ 不使用SQLite | 专用消息队列+时序数据库（InfluxDB） | 第31天开始新建 |

### 9.5 SQLite专属优化方案
#### 9.5.1 性能优化
1. **开启WAL模式**：将读写分离，写入性能提升10倍以上
   ```sql
   PRAGMA journal_mode=WAL;
   PRAGMA wal_autocheckpoint=1000;
   ```
2. **设置合理的缓存大小**：
   ```sql
   PRAGMA cache_size=-20000; -- 20MB缓存
   PRAGMA temp_store=MEMORY; -- 临时表存储在内存中
   ```
3. **使用预编译语句**：避免重复编译SQL，提升查询速度
4. **定期执行VACUUM**：整理数据库碎片，减少磁盘占用
5. **分库分表**：将大表拆分成多个小表，提升查询效率

#### 9.5.2 数据同步优化
1. **增量同步**：只同步变更的数据，不同步全量数据
2. **异步同步**：同步操作在后台异步执行，不影响用户体验
3. **断点续传**：同步中断后，下次从断点继续，不重复同步
4. **冲突解决**：采用「本地优先」策略，本地数据覆盖云端数据，避免冲突
5. **数据压缩**：同步的数据采用LZ4压缩，减少带宽占用

#### 9.5.3 离线模式支持
- 所有单能力都支持离线模式，用户断网时，所有任务都在本地执行
- 数据存在SQLite中，联网后自动同步到云端
- 离线模式下，积分和任务记录会在联网后自动结算和同步
- 支持本地备份和恢复，用户可以随时备份自己的SQLite数据库

### 9.6 旧平台与新架构的集成
#### 9.6.1 API网关集成
- 统一API网关兼容旧平台的所有API接口
- 旧API请求自动转发到旧后端，新API请求转发到新后端
- 逐步将旧API迁移到新后端，用户无感知
- 所有API请求都经过ASS安全网关，确保安全

#### 9.6.2 前端集成
- 旧平台的前端页面保持不变，用户可以继续使用
- 在旧平台的页面中添加新功能的入口，引导用户使用
- 新功能以弹窗或侧边栏的形式集成到旧平台中
- 逐步将旧页面替换为新页面，用户无感知

#### 9.6.3 数据集成
- 旧平台的所有数据自动同步到新架构
- 新架构的所有数据自动同步到旧平台的SQLite数据库
- 用户在旧平台和新平台之间无缝切换，数据完全一致
- 支持一键迁移所有历史数据到新平台

## 第十一部分 商业化与变现体系
### 11.1 核心定价策略
采用**免费+会员+企业版**的三级定价策略，兼顾个人用户和企业用户：

#### 11.1.1 免费版
- **额度**：每天10次任务执行，1GB内存，1核CPU
- **功能**：所有基础单能力、本地执行、基础安全扫描
- **限制**：不支持P2P分布式执行、不支持大文件、不支持AI推理
- **目标**：吸引用户，培养用户习惯，转化为付费用户

#### 11.1.2 个人会员版（399元/年，39元/月）
- **额度**：无限次任务执行，16GB内存，8核CPU，10GB GPU
- **功能**：所有1000+技能、P2P分布式执行、前端TF推理、全链路安全扫描、自动漏洞修复、审计报告
- **额外权益**：优先调度、专属客服、积分兑换折扣
- **目标**：个人开发者、学生、自由职业者

#### 11.1.3 企业版（9999元/年起）
- **额度**：根据企业需求定制，支持无限并发，1TB内存，128核CPU，100GB GPU
- **功能**：所有个人版功能+私有化部署、数据不出域、等保合规、定制化开发、专属技术支持、安全保险赔付（最高1000万）
- **额外权益**：专属节点、SLA保障、定制化技能开发、API接口
- **目标**：中小企业、大型企业、政府机构

### 11.2 其他变现方式
#### 11.2.1 技能市场分成
- 免费技能：平台获得广告收益的30%
- 付费技能：平台获得销售收入的20%
- 企业定制技能：平台获得定制费用的10%

- 按调用次数收费：0.001元/次起
- 按资源消耗收费：0.003元/核·小时
- 企业包年：9999元/年起，无限次调用

#### 11.2.3 算力交易
- 用户可以将自己的算力卖给其他用户，平台收取10%的手续费
- 企业可以购买专属算力节点，平台收取20%的服务费

#### 11.2.4 广告收入
- 免费用户的结果页展示少量精准广告
- 技能市场的官方推荐位广告
- 官网和推广页面的广告

#### 11.3.1 免费用户转化
- 免费用户使用3次后，显示强筛选提示："老骇说：白嫖3次够了，想保命，就开会员"
